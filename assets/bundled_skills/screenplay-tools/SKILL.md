# 剧本工具使用规范

先定位当前作品与任务目标，再按业务环节读取附件。剧情、对白、分镜和提示词写法使用匹配的创作技能；视频提示词的 Shot 格式由「剧本制片」提供，本技能只负责操作契约。

## 与界面名称对齐

| 用户在界面看到的名称 | 操作对象与边界 |
|---|---|
| 视频（导航入口）、制片 | 同一工作区的两种说法，包含分镜、画布与列表视图；指引界面操作时使用“视频”。结合当前视图和选中对象区分工作区、单个视频节点与视频文件，不因入口名称排除图片或音频操作 |
| 分镜、AI 拆分镜 | 已编入场次的制作条目，可为图片或视频；在 `/clips` 中以 `is_storyboard=true` 筛选，一条分镜的提示词可包含多个 Shot 镜头 |
| 视频、图片、音频 | 制作画布中的对应媒体节点；独立视频不因放在画布上就进入成片 |
| 画布、制作画布、人物参考图节点 | 集下的画布与人物参考图节点位于 `/episodes/{episode_id}/production/canvas`；`/canvas` 仅用于构思画布。具体操作前读取制作画布附件 |
| 导演台、导演构图、导演预演 | 用站位、关键姿势、整体运动和机位安排空间关系与镜头调度，输出构图静帧或白模预演；不提供动作库或自动表演 |
| 剪辑、多轨剪辑、分割 | 剪辑工程及时间线片段，使用「媒体处理与剪辑」；“分割”不是 AI 拆分镜 |
| Seedance 合规校验 | 把图片素材认证进渠道私域素材库，对应 `Run assets certify`；流程见分镜与媒体节点附件 |
| 导出本集、成片 | 本集 `editing_id` 对应的剪辑工程，使用「媒体处理与剪辑」导出；制作画布不直接合成成片 |

查询整集分镜用 `/clips?episode_id=…&is_storyboard=true`，只看视频分镜再加 `kind=video`。未关联场次的独立媒体不属于分镜；空白或未生成的场内条目仍是待完善分镜，不按标题、提示词或采用结果是否为空排除。视频分镜的 `duration_ms` 是计划时长，不证明正文容量或实际成片时长。

先结合用户当前视图、选中对象和读取结果定位。“第 2 个分镜”通常指一条场内制作条目，“Shot 2”指该条提示词内的镜头；仍无法确定目标时先澄清，不用内部 clip 名称猜测。反馈沿用界面名称，不把“分段”另造为一种资源。

## 按任务读取附件

| 任务 | Reference |
|---|---|
| 读取或修改季、集、场次与正文元素 | [剧本结构与正文](references/screenplay.md) |
| 读取制作设置、创建片段、配置模型、绑定输入、修改提示词引用、Seedance 合规校验、生成与采用结果 | [分镜与媒体节点](references/clips.md) |
| 查询风格、新建或编辑自定义风格，设置剧本默认风格、节点独立风格、无风格与继承 | [视觉风格](references/styles.md) |
| 创建或整理制片节点、导入素材节点、调整布局、视频节点截帧／分离音轨／静音／裁剪、图片派生与预设草稿、宫格切分与高清、全景取景 | [制作画布](references/production-canvas.md) |
| 调整导演台人物、姿态、路径、机位、切镜和时间轴，检查画面和刷新预览 | [导演文档](references/stagings.md) |

复制 `<skill_resources>` 中的 `reference-list` 调用列出附件，再用 `reference-get` 读取所选文件；`name` 使用「剧本工具使用规范」，`path` 使用返回值。只加载本次任务涉及的附件，已完整读取且仍在上下文中的不重复读取。需要依据附件确定工具、参数或步骤的调用，等待附件返回后再生成，不与附件读取放在同一批。

作品内容的路径和字段以实际 Read 返回及 `/_schema` 为准；素材查询与导演调度使用 `Run assets` / `Run stagings`，导演文档用 `Run stagings read` 读取，不能通过 `Read /stagings/...` 读取。导演命令参数见导演文档附件；其他命令按对应附件的说明查询。不要猜 ID，不把局部读取当成完整资源。写入后回读，保留无关内容与身份。制作画布上一批节点创建、连线或派生完成后，按制作画布附件检查并整理本次节点的布局再交付。

在 Codemode 中执行单次原子调用时，通常直接 `await`，让失败详情返回。确需捕获错误并继续处理独立任务时，输出异常的 `error_code`、`error` 和 `hint`；具体原因在 `error`，不能只输出 `message` 中的错误码。按错误定位参数后再重试，不通过反复写入猜请求结构。

需要查询媒体渠道与真实模型能力时，加载「系统管理」的模型查询附件。处理本地文件、剪辑时间线或跟踪后台操作时，加载「媒体处理与剪辑」对应附件。风格查询、自定义与设置的参数、流程见视觉风格附件。Run 命令是否可用以当前会话 `Run help` 为准；不可用时说明缺少的能力，不虚构调用或成功结果。
