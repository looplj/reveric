# 画布作品工具

画布作品是整窗的制作画布。视频节点就是界面中的“分镜”，一条分镜可以包含提示词中的多个 Shot 镜头；图片与音频节点用于对应媒体生成。文本节点保存说明或共用提示词，剪辑节点持有可编辑时间线，素材节点引用已导入文件，导演台用于布景与机位，宫格组组织拆图结果。

“导出成片”指某个剪辑节点的工程；存在多个工程且目标不明确时先确认。正式成片由用户在剪辑界面导出，文件处理与剪辑操作交给「媒体处理与剪辑」。制作方法和提示词格式按任务加载「剧本制片」。

## 路径与定位

- `production/settings`：作品默认风格、比例与清晰度。
- `production/canvas`：画布及其 `nodes`、`edges`。
- `production/clips`：制作片段，其 `generations` 保存生成记录。

画布作品暴露 `profile` 和 `production`。`profile` 与小说、剧本相同。其余 shared 组以及小说、剧本集合不开放。人物、场景和道具的外观依据来自用户上传的剧本、素材或文本节点。字段与操作契约按需读取 `/_schema/production`，沿用工具返回的真实路径和 ID。

画布作品没有 `is_storyboard` 或排序字段，成片顺序由剪辑时间线决定。用户说“第 N 个分镜”时结合标题、已读内容和对话定位；无法确定就询问，不用坐标或创建时间猜编号。

## 从上传剧本开始

使用「媒体处理与剪辑」读取聊天附件，确认实际剧本和任务范围。按原文顺序创建分镜并排版；共用的人物、场景或风格描述可按「剧本制片」写入文本节点，单个分镜的动作与逐字对白留在它自己的提示词中。已有节点先读后改，避免重复创建。用户只要拆分镜或文字草稿时不发起生成。

一批节点创建、连线或派生完成后，按「制作画布」附件检查并整理本次节点的布局再交付；只移动本次新增节点不需要确认。AI 修改不进入用户的画布撤销记录。批量删除或批量移动已有节点前先确认范围，保留无关节点和已有输入；交付区分配置保存、任务提交、结果生成与结果核验。
