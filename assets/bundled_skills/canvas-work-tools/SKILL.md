# 画布作品工具

画布作品是整窗的制作画布。视频节点就是界面中的“分镜”，一条分镜可以包含提示词中的多个 Shot 镜头；图片与音频节点用于对应媒体生成。文本节点保存说明或共用提示词，剪辑节点持有可编辑时间线，素材节点引用已导入文件，导演台用于布景与机位，宫格组组织拆图结果。

“导出成片”指某个剪辑节点的工程。存在多个工程且目标不明确时先确认。导出成片为画布视频节点时加载「媒体处理与剪辑」。

## 路径与定位

- `profile`：作品资料。
- `characters`：角色档案。“补全主角信息”默认指角色档案：先读取已有角色，找到主角后用 Write 补充其档案；首次建档用 Create。人物设定以已有档案、用户提供的剧本、素材和文本节点为依据。
- `production/settings`：作品默认风格、比例与清晰度。
- `production/canvas`：画布及其 `nodes`、`edges`。节点的 `id` 和 `path` 指向画布卡片本身。
- `production/clips`：制作片段，其 `generations` 保存生成记录。读取分镜提示词时，若已找到 `ref_type=production_clip` 的画布节点，用该节点返回的完整 `ref_id` 读取 `production/clips/{ref_id}`。若尚未定位片段，先读 `production/clips?view=summary`，再沿匹配条目的 `path` 读取详情。

用户还要求“关联节点”时，用角色 ID 定位或创建绑定该档案的图片节点；具体做法见[分镜与媒体节点](references/clips.md)。角色字段查 `/_schema/characters`，制作资源从 `/_schema/production` 查询，沿用工具返回的路径和 ID。

成片顺序由剪辑时间线决定。界面“分镜”指视频节点，“Shot N”指单条节点提示词里的内部镜头；用户说“第 N 个分镜”时结合标题、已读内容和对话定位，有歧义时向用户确认。

## 从剧本或创意开始

有上传剧本时，使用「媒体处理与剪辑」读取聊天附件，确认实际剧本和任务范围，按原文顺序创建分镜并排版。没有剧本、用户直接授权创作短片时，确定观看重点和镜头，确保每个节点的标题、提示词、输入与配置完整可执行。

共用的稳定设定可以写入文本节点，单个分镜的动作、逐字对白和阶段状态留在它自己的提示词中。风格设置与文本输入的展开方式分别见「视觉风格」「分镜与媒体节点」附件，已由风格配置提供的内容不再抄入共用文本。已有节点先读后改，避免重复创建。用户只要拆分镜或文字草稿时不发起生成。

一批节点创建、连线或派生完成后，按「制作画布」附件检查并整理本次节点的布局再交付；只移动本次新增节点不需要确认。AI 修改不进入用户的画布撤销记录。批量删除或批量移动已有节点前先确认范围，保留无关节点和已有输入；交付区分配置保存、任务提交、结果生成与结果核验。
