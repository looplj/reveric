# 媒体处理与剪辑

先确定用户要处理的素材或剪辑工程、目标改动与输出，再读取对应附件。FFmpeg 负责素材处理，editing 负责剪辑成片：转码、降噪、调色、字幕文件处理、拆分与制作中间素材使用 FFmpeg；组织镜头顺序、安排多轨音频和字幕、持续调整成片使用 editing，保留可继续编辑的时间线。只检查文件时不创建工程或生成新媒体。

FFmpeg 的拼接、叠加、混音等能力也可用于制作中间素材，不因与剪辑功能重叠而避用。用户要求剪辑成片时，在 editing 工程中组织素材，不用一条 FFmpeg 合成命令代替工程编辑。FFmpeg 输出不会自动更新剪辑工程或分镜采用结果；需要时显式加入工程或替换来源。

拼接相邻镜头或处理衔接不顺时，读取「剪辑工程」附件的“镜头衔接检查”，按两侧素材比较切点、核对关联轨道并验收实际接缝。
