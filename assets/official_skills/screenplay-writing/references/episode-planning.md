# 分集

按人物行动造成的变化划分剧集，再用目标时长检查内容容量。

## 确认范围

读取故事方向、目标集数与集长、已有大纲及相邻集。用户或作品规则已给出的规格直接使用；正式按固定规格分集前补齐缺失的集长。尚在探索规模时，可以提出候选集数及依据，标明它们仍是建议。

改编中的重大取舍尚未决定时先读 [改编](adaptation.md)。原创故事从人物追求和阻力开始。修改一集时保留其他集的既定安排，确有连带影响再指出。

## 排出一集

依次落实五件事：

1. **起点**：从上一集继承什么处境，本集从哪个行动开始。
2. **目标**：谁想在本集完成什么，为什么现在必须行动。
3. **推进**：尝试遇到怎样的回应，人物因此怎样换策略或付出代价。
4. **结果**：本集完成了什么、失去了什么，或改变了哪段关系。
5. **衔接**：结束后留下什么事实或未完行动，下一集从哪里接起。

把主要行动排成节拍，再按时间、地点与行动连续性划成场次。节拍和场次数量由故事决定；收尾可以是悬念、决定、后果或余韵，不强制每集反转。

## 开场、推进与收尾

开场让观众找到人物、处境和未决的事；预叙开场须能辨别时间关系，后文确实解释其结果。同一冲突可以跨集延续，但每集应改变信息、关系、代价或行动机会，而非重复同一轮争吵。

转折看旧办法或旧理解是否需要改变，回报看承诺是否兑现、关系是否变化。收尾可以是悬念、决定、后果、暂时安定或余韵，不靠无关事故延长已经完成的情绪。主题由选择的后果显现，不给每集先分配一句道理。

## 交付样式

可用分集表或分集短文。每集应能读出目标时长、行动顺序、局部结果与下一集衔接，不提前写成整场对白。下面是虚构的单集梗概示例：

> 求助者要取得门禁记录，先以举报施压。保安指出记录也会暴露求助者的违规进入，拒绝替他承担责任。求助者最终在申请上签下真名，保安才开放查询。记录中出现一次不应存在的进入时间，成为下一集调查的起点。

这里一集的变化是从匿名索取到承担责任；下一集应使用新获得的记录推进，不再重复索要记录。

交付前核对关键铺垫与相邻集状态。内容预算与正文核对按 [时长估算](duration-estimation.md) 处理。


## 三种层次分开记录

- 系列层：核心追求、主要对抗、人物长期变化和结局承诺。
- 单集层：当前目标、选择与局部结果。
- 场次层：谁在此时此地做什么，造成什么变化。

单集梗概不应重复整部故事的概念介绍。场次也不需要各自承担完整人物弧。

## 用交接状态连接相邻集

只追踪会影响下一步的事实：

| 维度 | 应交接的内容 |
|---|---|
| 时间与位置 | 事件先后、经过多久、人物到达或离开的依据 |
| 身体与物件 | 伤势、服饰变化、钥匙或证据由谁持有 |
| 知情范围 | 谁见过哪条线索，谁误信什么，观众知道多少 |
| 关系与筹码 | 刚许下的承诺、破裂的合作、交换条件和欠账 |
| 未完行动 | 上集最后正在发生什么，本集如何承接 |

不要每集复制所有设定。需要核对正文事实时读取实际场次；大纲中新写的事件不能作为已经发生的事实。

## 安排长线回报

为重要承诺找到铺垫、推进与兑现位置。每次推进应改变理解或后续行动，不能只重复提醒“这件事还没解决”。回报可密可疏，取决于题材与既定节奏，不设统一隔几集必须出爆点。

节奏同时考虑外部压力与情感负荷。追逐之后的安静场景可以处理失去同伴的后果；它有作用，不应只因没有新敌人而删除。

## 压缩、扩展与重排

压缩先合并功能重复的试探和解释，保住选择及结果。扩展需要新增有效阻力、关系变化或后果，不把原来的动作拆成两集拖延。

重排一集之后，检查：

1. 该集所需的事实是否已经出现？
2. 揭示是否早于原先约定，哪些人物因此提前知情？
3. 前一集结尾和后一集开场是否仍接得上？
4. 人物、地点或道具的引用是否仍存在？
5. 移走的回报是否让原位置只剩等待？

超出当前授权范围的连带改动先列明，不能在局部改稿中悄悄重写整季。

## 最小交接示例

第 4 集结尾：林序交出备份卡换回同伴，但对手尚未发现卡内有缺页；观众看见他保留了纸质索引。同伴不知道缺页的事。

第 5 集开场必须保持卡片归属与双方知情差异。可以让同伴因误解质问他，但不能让同伴直接说出“你留了索引”，除非补上发现依据。
