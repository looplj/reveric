# 剧本制片

剧本作品中，界面导航“视频”和用户所说的“制片”指同一工作区；画布作品直接提供制作画布，两种作品均适用本技能。指引界面操作时使用“视频”；技能加载名称仍为“剧本制片”。“视频”也可能指单个视频节点或文件，结合当前视图、选中对象与任务区分，不把工作区名称当作媒体类型限制。

将剧本中的动作、对白和戏剧变化落实到可编辑的片段与视频提示词。界面中的每条“分镜”对应一个图片或视频制作条目，视频分镜可以包含提示词中的多个 Shot 镜头；“AI 拆分镜”创建或修订这些分镜。镜头写在 prompt 中，不创建独立镜头资源。

## 进入任务

路径、字段、素材引用和执行契约由当前作品的工具技能维护：剧本作品使用「剧本工具使用规范」，画布作品使用「画布作品工具」，下文简称「工具技能」。读写分镜、读取制作设置或执行生成前加载对应附件，制作画布和导演台操作也由它负责；本技能提供制作方法与提示词格式。独立文件加工和多轨剪辑使用「媒体处理与剪辑」。

先定位本次范围的实际剧本和已有片段，再处理任务需要的编排、分镜或提示词；只改一段时不重做本次范围以外的内容。以原剧情、逐字对白、角色身份和关键道具状态为依据，不把梗概或旧草稿当成当前正文。

用户直接提供原文且只要文字草案时，可据此编排并说明缺失的视觉或模型条件；实际写入或生成前再核对应用资源与输入。草案应给出完整镜头表达，未确认素材放在交付说明中，不能伪造引用或声称已经具备生成条件。

## 按任务推进

用户要求制作视频时，继续完成所需的素材准备、补图和视频生成；已有合格素材优先复用。用户只要求拆分镜或修改提示词时，完成相应内容，并说明缺少哪些素材。结果采用与导出遵循「工具技能」对应操作规则。

整段制作先读 [制片流程](references/production.md)，完成素材检查与制作安排；准备或核验图片时再读 [图片资产与参考](references/image-references.md)，形象待定时追加人物选角与造型附件。局部修改只检查相关输入。

## 写入与交付

- 图片节点标题，以及工具技能要求维护的名称，按 [图片资产与参考](references/image-references.md) 核对；占位图命名按 [分镜指南](references/storyboard.md) 执行。沿用真实片段、节点和资产 ID 定位结果。
- 需要写入时保留已有资源 ID 和未改内容。片段提示词与剧本正文分别维护，不假定两者自动同步。只修改镜头表达时保留剧情与逐字对白；用户要求调整原文时，再同步受影响的分镜。
- 写入或生成前确认真实素材和模型能力，缺少条件时列明缺口；各操作的参数与限制遵循对应内置技能。
- 新增或重新绑定参考时，人物、场景等图片已有当前画布的来源节点，就优先连接该节点；没有对应节点或用户明确要求固定历史图片时才直接引用资产。按「工具技能」的分镜与媒体节点附件定位来源并核对连线，仅修改提示词时不转换原有引用。
- 完成后回读本次实际写入，核对指定范围是否覆盖、相邻起止状态是否衔接、配置是否与内容一致、已有 ref 标签是否保留。
- 区分“片段已保存”“参考待绑定”“待生成”和“实际结果已核对”，不以提示词完成代替视频完成。
