# 剧本制片

界面导航“视频”和用户所说的“制片”指同一工作区，两种说法均适用本技能。指引界面操作时使用“视频”；技能加载名称仍为“剧本制片”。“视频”也可能指单个视频节点或文件，结合当前视图、选中对象与任务区分，不把工作区名称当作媒体类型限制。

将剧本中的动作、对白和戏剧变化落实到可编辑的片段与视频提示词。界面中的每条“分镜”对应一个已编入场次的图片或视频制作条目，视频分镜可以包含提示词中的多个 Shot 镜头；“AI 拆分镜”创建或修订这些分镜。镜头写在 prompt 中，不创建独立镜头资源。

## 进入任务

读写剧本与分镜、读取制作设置或执行生成前，加载「剧本工具使用规范」对应附件；制作画布和导演台操作也由该技能负责。它维护路径、字段、素材引用和执行契约，本技能负责制作方法与提示词格式。独立文件加工和多轨剪辑使用「媒体处理与剪辑」。

先定位本次范围的实际剧本和已有片段，再处理任务需要的编排、分镜或提示词；只改一段时不重做整集。以原剧情、逐字对白、角色身份和关键道具状态为依据，不把梗概或旧草稿当成当前正文。

用户直接提供原文且只要文字草案时，可据此编排并说明缺失的视觉或模型条件；实际写入或生成前再核对应用资源与输入。草案应给出完整镜头表达，未确认素材放在交付说明中，不能伪造引用或声称已经具备生成条件。

按任务选择附件，在执行对应环节前读完，不预读全部内容。复制 `<skill_resources>` 中的 `reference-list` 调用列出附件，再用 `reference-get` 读取选中文件；`name` 使用「剧本制片」，`path` 使用目录返回值。已读取且仍在上下文中的附件无需重读。

从剧本制作整场或整集时，先确定片段编排，再按模型条件安排镜头和时长，最后完成提示词与写入。局部修改直接进入所需环节，不重跑整套流程。

整集拆完分镜后，按当前集与场次归属读取视频分镜，用 Codemode 求和计划时长并保留缺失项数量，再与用户说明或作品智能体规则中的每集时长对照；不口算改写工具返回的合计，不把旧故事状态里的集号当作当前集号。明显偏短或超出时，向用户说明差距，以及它来自剧本内容量还是拆分方式；不靠拉长镜头、加空镜或删戏来凑时长。

分镜配置和提示词中的时间区间属于计划值，不能作为正文实际耗时的证据。使用试读、配音或视频校准时，先确认对应的正文版本和覆盖范围；部分内容的时长不能代表整集。即使片段总时长符合目标，也要核对对白与动作能否在各自窗口内完成。

配方是可迁移的写法，不是固定剧情或参数。先按本次目标选最接近的范例，再替换成已读取的真实人物、道具、空间和逐字对白；保留方法，删除不适用的段落。场景缺少已确定外观或模型时，说明草案假设，不把教学例子的设定补成作品事实。需要成稿时给完整可用正文，不只返回原则、空模板或待填清单。

人物参考按下游任务选择：锁五官与神态优先清晰的单张头部特写，控服装采用无头正面身体、背面与独立头部参考，建模或大幅转面采用几何对齐的多视图。竖版定妆四视图是服装与定妆展示的一种配方，不是所有人物资产的必备格式；选择与验收见 [图片资产与参考](references/image-references.md)。

先检查人物设定、已有图片和下游输入要求，直接复用满足任务的素材，仅补实际缺口。不为凑视图重生成，也不强制先做选角图；形象待定时再询问是否选角。生成和补图仍以本次授权为准，只讨论或改提示词时列出缺口，不自动生成。检查实际提交会叠加的风格，避免全剧的工业、灰暗或破旧氛围改写角色的阶层与衣料。

## 写入与交付

- 图片节点使用能辨认对象和用途的标题，例如“江小白｜定妆四视图”“镇北侯府正厅｜场景”“第1场·踹飞撞柱｜占位·起始站位”。标题写入现有图片片段的 `title`，不画进图片；沿用真实片段、节点和采用资产 ID 定位结果，不假定标题会自动成为资产名称或文件名。占位图按当前分镜与动作起点制作，不先查找、读图筛选旧占位图以求复用。
- 需要写入时保留已有资源 ID 和未改内容。片段提示词与剧本正文分别维护，不假定两者自动同步。只修改镜头表达时不擅自改写剧情；确需调整原文时按用户授权处理。
- 按用户授权执行分镜编辑、参考绑定、生成、采用或导出，不把“写提示词”自动扩大成生成任务。先确认真实素材和模型能力，缺少条件时列明缺口；各操作的参数与限制遵循对应内置技能，不自行编造。
- 新增或重新绑定参考时，人物、场景等图片已有当前画布的来源节点，就优先连接该节点；没有对应节点或用户明确要求固定历史图片时才直接引用资产。按「剧本工具使用规范」的分镜与媒体节点附件定位来源并核对连线，仅修改提示词时不转换原有引用。
- 完成后回读本次实际写入，核对指定范围是否覆盖、相邻起止状态是否衔接、配置是否与内容一致、已有 ref 标签是否保留。
- 区分“片段已保存”“参考待绑定”“待生成”和“实际结果已核对”，不以提示词完成代替视频完成。
