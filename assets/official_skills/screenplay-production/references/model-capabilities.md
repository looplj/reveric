# 模型能力与配置

## 先确认执行条件

按「系统管理」的媒体渠道与模型查询附件和「工具技能」，读取实际 `provider_id`、`model_id`、支持模式、规格限制与默认配置；视频模型同时记下 `catalog_model_id` 以路由提示词格式。优先沿用分镜已选型号；能力未知或不可用时如实说明，不根据品牌或相似名称猜限制，也不因配置可读就推定远程额度或网络已通。

影响制作设计的核心条件：

| 条件 | 对分镜与提示词的影响 |
|---|---|
| 确切型号与渠道 | 不把 mini、fast、不同版本或相似命名当成同能力，不擅换用户指定模型；不同渠道同名模型也可能不同 |
| 单次时长 | 决定一次生成装多少镜头；字段单位与取整规则见「工具技能」 |
| 画幅与分辨率 | 先定构图再排动作与机位；使用模型接受的精确枚举值，文字写“4K”不改变输出参数 |
| 输入模式与参考用途 | 区分纯文本、首帧、首尾帧与全参考；人物身份图不等于首帧，视频参考不自动等于原生延长 |
| 素材数量与规格 | 核对数量、尺寸、文件大小与音视频时长上限，只传入本段真正需要的素材 |
| 声音与口型 | 分别确认音频参考、生成音轨与逐字口型控制能力，按需配置或规划后期 |
| 提示词长度与可控度 | 优先保住动作因果、连续性与对白，用可见行为和时间区间控节奏，删掉重复修饰 |

## 用实际能力安排制作

图像路由见 [图像模型提示词适配](image-prompts.md)；图像与视频分开查询、分别套用各自附件，不把视频格式或 `catalog_model_id` 约定套给图像。

以本次查询返回的时长集合、画幅、分辨率、模式与媒体上限安排内容，参数原样保留大小写。更换模型、输入模式或实际素材后重新核对配置与总时长。未选定模型时可写暂定时长草稿并注明待定，不把猜测限制当成已验证。

## 将同一镜头改写到不同输入方式

先区分当前提供了什么输入，再决定文字补足哪些信息（具体语法见 [视频提示词](video-prompts.md) 及各模型子文档）：

| 任务条件 | 提示词怎样变化 | 不能偷换的条件 |
|---|---|---|
| 纯文本生成 | 独立建立主体外观、场景布局、开场动作与光线，不写“照图” | 外观缺失时先标明草稿假设 |
| 已有首帧 | 从图中真实姿态与持物起步，重点写后续运动、声音与终点 | 不让首帧已坐下的人再从站立坐下 |
| 首尾帧 | 两端锁定起止画面，正文专写中间过程、接触与速度变化 | 两端身份、场景或状态冲突时先修输入 |
| 多参考输入 | 分开身份、状态、空间、构图与风格，删掉参考图已承担的外观重复描述 | 不把身份图站姿强加给分镜，也不无差别塞入全套参考 |
| 动作参考／预演 | 写明借用路线、机位或节奏的哪部分，再补本剧造型与表演 | 动作参考不自动带入人物服装，预演不等于成片 |
| 已有片段续拍 | 从实际尾部状态延续，区分“重开下一段”与渠道支持的原生延长 | 不因接受视频输入就声称支持原生延长 |

例如同一“推门入室”：无参考须交代门位与开启方向；首帧版只写图中手如何压下把手推开；动作参考版写明只借推门路线，外貌与门型依本剧。若实际首帧门已全开，应换图或承接开后动作。

切换模型或约束收紧时的适配方法：

- **单次时长变短**：在语义或完整动作边界拆开，分别重设各段起点与时间区间，不把长动作等比压缩成快放。
- **可用参考变少**：优先保住最难维持的身份、空间或物件；需同时锁多要素且支持帧约束时，改用正式合成关键帧。
- **不支持所需声音／口型**：保留台词文本并标明改由配音或后期合成。
- **不支持复杂切镜或长提示词**：先删重复外观与氛围词，再降低单次动作负载，不删决定剧情的事件、说话人与终点。
- **画幅改变**：重检人物间距、遮挡与证据文字可读性，不只改写文字里的比例字样。

## 模型模式边界与关键帧准备

确认当前型号支持的 `modes` 与 `reference_roles` 中的帧角色后，具体 `reference_mode` 选用、输入过滤、音色限制与帧 role 提交规则遵循「工具技能」。模型侧仅额外核对两项：

- 当所选型号**仅支持原生首帧／首尾帧**且画面同时要求人物、场景与道具成立时，先合成并核对正式关键帧后再送入生成，不把互斥的输入模式混在一起要求接口同时接收。
- 使用原生首尾帧约束且首尾两帧构图、视角或尺度跨度较大或时距较短时，生成后核对中间动作过渡，避免出现中间形变或硬跳。
