# 通义万相提示词

适用于通义万相 3.0、2.7 与 2.6，具体型号按 `catalog_model_id` 查 [视频提示词](video-prompts.md) 的模型对照。内容原则见 [视频提示词](video-prompts.md) 与 [分镜指南](storyboard.md)；本附件只规定万相的结构与标记，取代通用 Shot 格式。

## 公式

- 文本生成：`主体（外观）+ 场景（环境）+ 运动（动作与运镜）+ 美学控制（光线、景别、构图）+ 风格`。
- 首帧或首尾帧生成：画面已经确定主体、场景和风格，提示词只写运动、情节、台词和运镜，不复述图中外观。
- 参考生成：`参考指代 + 动作 + 场景 + 台词 + 背景音乐`，在提到某个人物、物件或场景的位置放对应 ref 标签，写清它在本镜承担什么。

## 多镜头与时间

万相按时间戳理解多镜头。先写一句总体描述（视角、事件、基调），再逐镜写：

```text
镜头1[0-3秒] 运镜或切换方式，主体动作与表情，位置变化。
镜头2[3-7秒] 硬切，固定机位，……
```

- 时间用整数秒，镜头首尾相接，最后一镜的结束秒数等于生成时长；一种括号写法用到底。
- 每镜通常 2–5 秒，一镜一个主要运镜。
- 只要一个连续镜头时，写“生成单镜头”，并按“起始 → 过程 → 结束”写动作阶段，不写镜头编号。
- `wan-2.6` 的多镜头还依赖生成配置；写了镜头结构但配置仍是单镜头时，以配置为准，需要先按操作契约调整。

## 台词与声音

- 台词写成 `说话人身份 + 语气、语速、音色 + 说："原话"`，原话逐字保留；多人对话每句单独写出说话人。
- 音效写“声源材质 + 行为 + 环境”，如“木门合页缓慢转动发出的干涩吱呀声，走廊里有轻微回声”。
- 背景音乐写配器与风格；不需要时明确写“无背景音乐”，不要台词时写“无台词”，否则模型可能自行补上。
- 音色需要参照某段音频时，在对应说话人后放该音频的 ref 标签并写明“音色参考”。

## 负面内容与改写

- `wan3.0-*` 没有独立负面字段，需要排除的内容在提示词末尾写一行“避免：……”，只列不想出现的东西，不重复正向描述。`wan-2.6`、`wan-2.7` 的负面字段是否可用以运行时配置为准。
- 智能改写（prompt_extend）会扩写短提示词。已经写好完整分镜和逐字台词时，改写可能改动结构；是否关闭按配置与用户意图处理，不擅自修改。
- 中英文都可用；整条提示词保持一种语言，台词保留原语言。

## 示例

假设生成 8 秒、`wan3.0-video`、已有林岚与周明的人物参考：

```text
夜间室内，两人隔桌对坐的告别戏，暖色台灯从画面左侧照亮木桌，写实电影质感。
镜头1[0-4秒] 中景，固定机位。<ref input_id="…" label="林岚" />在画面左侧，用右手食指把一把钥匙沿桌面推向<ref input_id="…" label="周明" />，在桌沿内侧停住，指尖仍压着钥匙。周明看着钥匙没有伸手，随后抬眼。钥匙擦过木桌发出轻微摩擦声。
镜头2[4-6秒] 硬切，周明近景，沿用左侧暖光。周明压低声音、语速放缓地说："你真的要走？"
镜头3[6-8秒] 硬切，桌沿钥匙特写，微俯拍。林岚的食指松开并退出画面左侧，钥匙留在原处。
无背景音乐。
避免：字幕、水印、多余人物。
```
