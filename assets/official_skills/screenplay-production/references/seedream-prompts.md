# Seedream 图像提示词

用于 Seedream 的生成、编辑与多参考组合。

## 写清用途与空间布局

先说明用途（场景参考、道具图、人物图或叙事关键帧），再描述主体状态与可见关系。复杂画面按前后、左右、上下组织，写出遮挡、尺度与视觉焦点，用自然语言代替形容词堆砌；画内文字用引号给出准确内容与所在位置。

场景参考图示例：

```text
雨夜钟表铺空场参考图，从门口平视室内。前景右侧为玻璃柜台，柜内三只怀表分开摆在深灰毛毡上；中景左侧为带木凳的修理台；后景墙面挂一只圆形挂钟，旁侧有通往后室的门。
修理台暖色台灯照亮工具与木纹，橱窗外冷蓝雨光映在玻璃柜台边缘。中央通道畅通，体现玻璃、黄铜与旧木的材质差异。
```

## 编辑与多图组合

局部修改时用可见位置或特征锚定目标，写清变化项与保持项；多张参考分别写清提取对象与用途（借服装时明确不继承原图模特与背景）。

以下假设人物图、服装图与场景图均已传入，正式使用时在对应位置插入真实 `<ref input_id="…" label="…" />`：

```text
保留人物参考中的面貌、发型与体型，将服装替换为服装参考中的深绿立领长衫，维持其领型、门襟与袖口结构，不继承服装图模特与背景。
人物站在钟表铺修理台旁，右手扶着桌沿，目光落在桌上怀表。维持场景柜台、门与挂钟位置，人物尺度与桌高协调，受原有台灯暖光照明并在地面落出接触阴影。
```

若传入带有清晰箭头、框选或涂抹标记的参考图，应说明标记控制的修改范围及成图是否去掉标记；草图转效果图时明确保留的布局比例与需补充的材质光线。需要组图时先确认当前入口是否支持多图独立输出，不把单张多宫格与多张独立输出混为一谈。

## 返修要点

发现多图串脸、服饰被场景带偏或区域指代不清时，优先在词句中补明对象方位或使用带视觉标记的参考图来收敛，不靠堆叠无关环境词修补。
