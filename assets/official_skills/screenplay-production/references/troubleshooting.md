# 结果诊断与改写对照

有视频产物时先看实际画面与音轨，无结果时先按「工具技能」检查提交状态与参数。只保留“修改后先用单变量验证、未看片不声称问题已解决”的原则；若替换已有镜头，需同步核对前后段衔接边界。

## 记录可复查的问题并定位根因

用结构化要素记录故障：`分镜与时间点 → 预期 vs 实测偏差 → 怀疑输入 → 保留项 → 单一修正 → 复查证据`。例如把“不够电影感”具体化为“2.8 秒预期盒底平推，实际腾空砸落”。

| 现象 | 第一检查点 | 合适修正范围 |
|---|---|---|
| 多段共有错脸、造型、房间或纹理模糊 | 共享角色／场景图与当前采用文件、分辨率 | **先重做或替换共享资产图**再复查下游，不在视频提示词里空补质感 |
| 仅单段换脸、换衣或阶段穿帮 | 本段参考绑定、共用节点文本与阶段设定是否冲突 | 修冲突来源与本段正文 |
| 首帧剧透或人物摆位已错 | 起始关键帧、占位图或预演文件 | 先修输入起点图；文字无法抹掉错图内容 |
| 动作漏拍、重演或持物跳变 | 任务是否过载、相邻起点是否重置 | 拆镜减少并行任务或调正切点，不靠删剧情掩盖 |
| 转身僵硬、起步脚滑 | 脚下支撑、重心转移与可见部位的联动 | 补写缺失的动作过程，保留原走位和终点 |
| 人物像贴进背景 | 人物亮面、阴影和场景实际光源是否一致 | 找出光源冲突，再写清场景光如何落到人物身上 |
| 动作发飘、打斗同质、高潮不兑现 | 受力因果、动作可读性、景别与时间分配 | 重排核心节拍与时长，不靠堆形容词或泛滥光效 |
| 台词截断、串人或口型不对 | 发声窗口、说话人归属、段长与原声音轨 | 重排节奏与声道用途或切分后期配音 |
| 文字水印、白模颜色被带入成图 | 实际输入图像内容与参考用途说明 | 清洗参考图或明确仅继承空间/路线，不堆叠否定词 |

## 典型故障改写对照

### 一、动作与声音互相打架

- **问题**：`值班员平稳推进铁盒，盒底沿木柜台滑动。声音：铁盒重摔柜台，尖锐金属撞击。`
- **改写**：正文与声音同步收束——`盒底始终贴着木柜台推进，仅有短促摩擦声；接稳瞬间停止。`同步检查其他 Shot 及音频参考，复查从头至尾不离台面。

### 二、首帧已经演完动作

- **问题**：首帧图是“推门人已站在屋内门内”，正文却写“站在门外伸手压把手开门”。
- **改写**：要么重画“人仍在门外、手伸向门把”的干净首帧；若确定采用门内起点图，则改由“站稳环顾室内”承接，同时说明开门过程已跳过。

### 三、单人镜头里塞进双人问答

- **问题**：`甲单人近景，看向乙，乙点头答：“他让我等你。”`
- **改写**：明确拆成两镜（先写甲近景看画外，再切乙近景看向画外并开口）；若必须留在一镜看甲反应，则写清乙**仅在画外发声**，去掉乙的可见点头。

### 四、单镜塞入过载任务

- **问题**：`环绕运镜中，甲递信给乙，乙转身跑向柜台加锁，同时说出整段长独白。`
- **改写**：按“观众此刻主看什么”拆分任务，不要求同段全部吞下：
  - 镜 1（交接）：双手递接信封并释放，固定中近景保住手部接触；
  - 镜 2（移动与行动）：移步柜台锁盒，与独占长台词分窗安排；
  - 镜 3（揭示与反应）：落锁后反应近景或特写。

### 五、续拍重演 + 取景与保持项打架

- **续拍重演**：前段实际已开窗、人物已起身，后段仍写“走到窗边准备开窗”。先看前段末帧再承接已开启状态。
- **景别与全身约束冲突**：`人物头肩特写，保持黑裤、系带鞋与全身比例` → 只保留本景别可见范围的保持项：`正面头肩近景，保留同款脸型、发型与立领口`。
- **局部禁字误杀必须出现的刻字**：`盒盖清晰写‘甲午’，画面禁止任何文字` → 正向声明精确内容与载体：`盒盖中央仅保留黑色手写体“甲午”二字`（不可靠时预留正面区域交给后期）。

### 六、预演或占位参考污染最终画面

- **问题**：`完全照参考预演一模一样输出。`（导致成片出现白模色块或僵硬关节）。
- **改写**：拆清各自来源——`预演仅提供各时刻站位、相对距离、走位路线与机位节奏；人物相貌服装取自人物参考，材质取自场景图，识别色与简模关节转为自然表演。`若预演缺必要动作，先补预演再提交。

### 七、动作飘轻、特效遮人或高潮只剩堆光

- **问题**：`两人高速闪现对轰、金光炸满屏后敌人倒地，结尾放出更大光波。`
- **改写**：回到“因果、可读性与局面变化”。写清**发力支撑 → 兵器或身体接触 → 受力滑动或破绽暴露 → 特效沿接触方向延伸但不遮挡主体轮廓**；结尾高潮必须兑现此前建立的弱点或路线突破，不靠反复加亮充当高潮。详见 [动作对抗案例](examples/shot-combat.md) 与 [破盾开路](examples/shot-stylized-action.md)。

### 八、转身与起步脱节

- **问题**：写了“抱着纸转向柜台走去”，成片里只有头转了，脚还朝原方向，身体直接滑过去。
- **改写**：`她把纸叠收到胸前，重心落到支撑脚，肩和胯随转身一起朝向柜台，另一只脚顺势迈出。`按景别写可见的支撑、重心变化和身体联动。若预演的转向或落脚点本身有误，先修预演。

### 九、人物受光和场景脱节

- **问题**：窗在人物侧面，人物两颊却像被正面灯均匀照亮。
- **改写**：`靠窗的脸颊和肩被冷天光照亮，背窗的半张脸落入阴影。她俯身靠近木台时，台面反出一点暖光，落在下颌和前臂内侧。`按实际光源写受光部位和阴影，有可见反光时再说明它来自哪个表面。若起始帧里的光位已经与场景冲突，先修起始帧。

## 单变量验证与停止重试

一次返修优先只针对最有证据的一项（如先修首帧或先拆过载动作），**不同时更换模型、参考图、机位与风格**，保证前后可对比。反复失败时回到输入依据、能力上限与取景拆解，不叠加“绝对、百分之百”祈使句或无依据自动连抽；需要改剧情、换受限型号或改用后期合成时先向用户说明确认。

只完成文字修改时交付“返修提示词／方案已更新，待重新生成并看片验证”，不写成“视频故障已解决”。
