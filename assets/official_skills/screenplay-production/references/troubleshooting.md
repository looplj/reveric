# 结果诊断与改写对照

有生成结果时看实际视频并试听；没有结果时先处理提交状态、配置或输入错误，遵循「工具技能」。本附件案例均为教学假设，不是对用户媒体的观察记录，也不证明改写后必然成功。

## 记录一个能复查的问题

记录“分镜／结果版本、发生时刻、预期、实际观察、可能相关输入、保留项、一次修正、复查证据”。例如：

> B 的 2.8 秒：预期盒底沿柜台滑动，实际出现腾空后砸落。人物身份和空间可保留。画面正文写平推，但声音仍写金属重摔；先改声音与相关动作残留，下一次检查完整推送过程。

“不好看”“不够电影感”无法定位故障。改成能比对的表现：人脸是否变化、哪个物件重复、哪句漏字、人物从哪一侧突然到另一侧。只能观察首尾帧时，保持中间动作与音轨未知；联系表可帮助定位疑点，但不能证明中间没有换脸或越轴。

## 先决定修哪里

| 现象 | 第一检查点 | 合适的修正范围 |
|---|---|---|
| 多段共享错误脸、造型或房间 | 共同人物图、状态图、场景图及当前采用文件 | 先修共享来源，再核对受影响片段，不盲目改全部 prompt |
| 只有一段换脸、换衣 | 本段参考绑定与局部文字是否冲突 | 修本段输入或描述，保留其他结果 |
| 静帧已错位、提前揭示 | 起始图片、分镜拼图、导演预演是否正确 | 先修输入起点，文字不能宣称错误图片已被纠正 |
| 动作缺失、重演、持物跳变 | 必需过程是否可见、任务是否过载、相邻起点是否重置 | 减少同一镜头同时承担的动作或重新拆镜；完整保留原事件 |
| 台词截断、串人或重说 | 发声窗口、说话人、段长与输入原声 | 局部重排节奏或明确声音用途，必要时提出后期方案 |
| 字、网格、白模外观被带入 | 实际输入是否包含这些内容、参考角色是否写错 | 清理或换输入，缩小继承范围，不靠无限负面词 |

## 对照一：动作改了，声音还在演旧动作

修改前：

```text
值班员把铁盒平稳推向林岚，盒底沿木柜台滑动。声音：铁盒重摔柜台，尖锐金属撞击回荡。
```

修改后：

```text
值班员平稳推送铁盒，盒底始终贴着木柜台。推送期间只有短促摩擦声；林岚接稳时声音停止，没有砸落动作或重摔声。
```

同时检查提示词其他 Shot、首尾状态和音频参考是否仍带着重摔要求。复查证据是铁盒从开始到停止始终接触台面，声音与运动一致。

## 对照二：首帧已经把剧情演完

修改前：首帧是“林岚双手抱着铁盒”，视频却从“值班员将盒子推给她”开始。

修改后先重作首帧：

```text
铁盒仍在值班员一侧柜台上，他的右掌压在闭合盒盖中央。林岚双手停在自己一侧桌沿，尚未接触铁盒。两人之间留有完整可推送的台面。
```

视频再写移手、推送、接稳。不能保留旧输入，只在视频正文添加“别从抱盒开始”。若用户明确采用抱盒图作为新起点，应解释交接已不属于当前片段可见过程，而不是静默删掉原剧情。

## 对照三：单人镜头被文字变成双人镜头

修改前：

```text
林岚单人近景，看向值班员，值班员点头回答：“他让我等你。”
```

需要看到回答时，改为两个明确镜头：

```text
林岚近景，视线从画面下方抬向画外右侧，画面里只有她。
随后明确切到值班员近景；他看向画外左侧，点头后说：“他让我等你。”
```

若决定全程留在林岚反应上，则写清值班员在画外发声，不描述其可见点头。正式提示词补齐对应 Shot 时间区间；两种处理选符合本镜职责的一种。复查实际人数、说话人和口型，不只看文本是否标了“单人”。

## 对照四：一条镜头塞进整套动作

修改前：“镜头快速环绕，甲递钥匙，乙接住转身开锁，门后人惊叫，甲在同一时间说完整长句。”

先保留事件顺序，再按主要观看任务拆解：

| 改写后的镜头职责 | 必需画面 | 不在本镜并行要求的事 |
|---|---|---|
| 钥匙交接 | 双手与钥匙，接触后释放，接收手不变 | 环绕、开锁、第三人反应 |
| 到达门前并使用钥匙 | 移动路径或明确的时空转接，手与锁眼可读 | 与长对白争夺同一个短窗口 |
| 门开后的揭示 | 门扇、门后人和可见反应 | 提前在首帧露出本应隐藏的人 |

这是一种分镜安排，不要求所有模型在一次生成里完成三镜。按实际时长、参考和能力决定同段还是分段；对白照原文安排，不改成无意义快念。复查原事件是否都保留、动作是否到达终点。

## 对照五：续拍重复已经完成的事

修改前：B 已经推盒、开盖；C 又写“值班员把盒子递给林岚，她打开看”。

修改后：C 从林岚看完盒内钥匙后的反应近景开始，盒子保持打开，钥匙仍留在盒内。首帧、持物描述与输入同步修改。若 B 实际未开盖，则不能套用这个修法；读取实际末态，选择修 B 或补未完成动作。原计划不是证据。

## 对照六：头像仍出全身、道具文字被清掉

头像修改前：“人物面部特写，保持黑裤、系带鞋、整套制服及全身比例。”

头像修改后：“正面头肩近景，头顶完整、下边缘到锁骨下方；保留同一脸型、发型和领口，服装其余部分不进入取景。”细节保持项只覆盖本景别可见部分。

道具修改前：“罗盘底面准确写 N-04，全画面禁止任何文字。”

道具修改后：“底面中央仅保留准确刻字‘N-04’，无额外商标、编号、字幕或图内说明。”无法可靠生成准确文字时，保留证据面并明确后期任务；文字未合成前不报告证据镜头通过。

## 对照七：参考预演变成最终白模外观

修改前：“所有内容完全照参考预演，一模一样。”

修改后：

```text
预演只提供各时刻的站位、相对距离、路线、入画时机与机位节奏。两个人物的身份和服装来自各自已提供的人物图，场景材质来自场景图。预演中对象颜色只是识别标记，不转成肤色或服装颜色；粗略关节动作改为自然表演，但不改变路线、接触时机或停点。
```

实际预演若缺少必须看见的交接，先修预演，不能同时要求严格照参考和凭空加入另一套动作。若改为无参考生成，应完整重写开场空间与动作，不只删除“照参考”三个字。

## 何时停止重试

一次修改优先针对最有证据的一项，保留其他条件便于比较。再次失败时回看实际输入、失败时刻和能力限制，不继续堆“绝对、必须、百分之百”或自动无限生成。可选替代包括修改取景、拆开动作、换合适的输入方式、局部图片编辑或后期处理；需要改变剧情或用户指定模型时，说明原因并由用户决定。

记录修后真实观察：改善了什么、仍缺什么、哪些判断仅为假设。只完成文字改写时交付“返修方案／提示词已修改”，不能写成“视频问题已解决”。
