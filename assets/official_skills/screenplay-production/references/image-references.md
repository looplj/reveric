# 图片资产与参考

## 先决定图片的用途

先读当前剧本、已有素材和本次镜头需要，优先复用已确认图片。身份参考、场景参考、风格参考和视频首帧解决不同问题：一张好看的气氛图未必能看清人物，一张人物设定图也未必适合直接做开场。只准备本次确实要用的图片，不为每个姿势、表情或机位另建一套资产。

图片提示词按“用途与主体 → 稳定特征 → 当前状态 → 构图与空间 → 材质和光线 → 必须保留及避免的误读”组织，省略无关项。只描述能在同一瞬间成立的画面；先做什么、再做什么，以及运镜、对白和声音变化留给视频提示词。图像模型和实际输入方式仍需查询，不假定它与视频模型相同。

需要完整成稿时读取 [图片提示词配方](image-recipes.md)：包含人物母版与派生图、状态变体、同场观察面、道具全貌与证据面、首帧合成、交接首尾帧和分镜拼图。

## 人物、场景与道具

| 参考对象 | 优先明确的内容 | 容易混淆的边界 |
|---|---|---|
| 人物 | 年龄、性别、年代与地域、社会身份；已确定的面部轮廓、体态和辨识细节；本场一套自洽的发型、服装形制、配饰与伤湿状态 | 稳定身份与临时造型分开；不为增加辨识度擅造疤痕、纹身，不把手持道具永久绑定给人物 |
| 场景 | 从哪个入口朝哪里看，门窗与固定物的相对位置，通行路线、尺度和主光来源 | 换角度不搬动门窗；天气、光照和临时摆设可以变化，变化需与本场一致；用于复用空间时宜做空场，人物走位交给镜头首帧 |
| 道具 | 轮廓、材质、相对尺度、握持或操作部位，以及开闭、完整或损坏状态 | 谁持有和是否打开属于当前状态；需要看清的文字、图案和功能面不能被构图遮住 |

## 人物形象先定事实

人物形象决定观众能否认出角色，实际制作前先落实主要人物的身份与本场造型参考，再完成依赖它的分镜输入和生成。文字拆镜可先规划，但缺少视觉依据时只算草稿。动笔前读取作品已有的人物设定、原著外貌描写和世界观；改编作品以原著描写为准，不用演员、通行同人图或模型印象替代。

首次设计或用户反馈人物平淡、像路人、身份不符时，先读取 [人物选角与造型](character-design.md)。本附件解决参考的复用与一致性，不能代替选角和服装设计；“同一个人”只证明没有换脸，不能证明这个人适合角色。

- 年龄、性别、年代与地域是整组图的根。三者在作品资料中找不到依据时先问用户，不默认当代，也不按题材猜测。
- 其余缺口按年代、地域、阶层和职业推断，并在交付说明中标出哪些是原文明确、哪些是推断，让用户只需核对推断项。
- 服装写到形制，而不是只写品类：领型、门襟、袖口、腰线、裤型或裙长、鞋、面料与磨损。只写“衬衣”“长裤”时，模型会画成当代成衣；非当代人物还要写明不出现的当代特征，例如修身剪裁、敞领、卷袖、运动鞋。
- 面部写能画出来的特征：脸型、眉眼形状与间距、鼻梁、嘴型、肤色、发际、发质与长短。“有书卷气”“五官普通”不能约束长相，会退回模型默认的模特脸；气质改写成表情、体态和姿势。
- 图片正文只写画面内容。“本集”“母版”“此图只规定身份”这类制片用语和流程说明对图像模型没有画面含义，放在交付说明里。

## 按下游任务选择人物参考

先明确参考要解决的问题：分镜、视频或换装中的人物参考，与建模、转面使用的结构图，采用不同形式。读取本次镜头与输入要求；用途仍不明确时先询问，不仅凭“人物资产板”或“三视图”的叫法决定布局。

| 下游任务 | 优先采用的素材 | 验收重点 |
|---|---|---|
| 人物参考：分镜、图生视频或换装中固定五官、骨相、神态与穿搭 | 下述竖版四区板，整板作为模型参考输入 | 面部有效分辨率、五官关系、年龄、肤色、发型与神态；领口、版型、肩腰线、材质褶皱、后背剪裁、发尾与鞋履；换装时明确身份与目标服装分别由哪张图提供 |
| 建模与转面：多视角生成或大幅环绕镜头 | 正、严格侧、背全身结构图，可横排或上下分区；按下游要求决定是否补其他角度 | 完整头身、统一尺度与姿态，头顶／肩／腰／膝／脚底高度对应，头身比与肩宽一致，避免透视缩放与结构错位 |

视图数量只由所需信息决定。多角度小脸可能出现细节不足或身份混淆；不要把“脸被平均化”或“裁掉脸必然提高服装权重”写成所有模型都成立的机制。按实际模型与输入方式检查输出，不能仅凭板式承诺锁脸、换装或环绕稳定。

四区板是送入图像或视频模型的参考输入，不是只供人看的展示板。人物镜头整板输入，不另以单张头肩特写替代，也不拆成多张；四区板只占一个参考名额。上方头肩格面部像素不足时提高整板分辨率或重新生成，不靠放大恢复细节。

### 人物参考输入：竖版四区配方

向模型提供人物参考时采用此方案。它放大正面服装、缩小完整背面，让模型同时获得清晰的五官与服装细节；这种尺度不同且缺少完整侧身的板式不能直接当作几何对齐的建模三视图。结构任务需另选同尺度、完整正侧背视图，不能只改排版名称。

- **画布与布局：** 规整四宫格、两列等宽、细线分隔；上方占画布 1/3，下方占 2/3。
- **左上正面、右上 90° 侧面头肩特写：** 头部与肩颈紧凑构图，完整保留发型。右上严格侧视，不以四分之三侧脸代替；精准保留五官、骨骼轮廓、妆容与神态。
- **左下放大正面服装展示：** 标准 A-pose，双臂自然微张；从肩颈下方至鞋底，头部完全出画，完整保留肩膀、双手、服装及鞋履。人物尽可能占满分区，明显比右侧背面人物更大，突出服装结构与材质。
- **右下背面全身展示：** 标准 A-pose，头与身体均背对镜头、不回头；从头顶至鞋底完整入镜，正常全身比例，展示背面发型、服装结构及鞋履。
- **身份与造型：** 同一个人物、同一年龄、肤色、发型、妆容、服装、配饰及身体比例。已有参考的已知部分忠实还原，未展示部分合理延续，不擅自增加复杂设计。修长自然的比例须服从原有体态；左下更大来自取景放大，不能拉长身体或改变肩宽。
- **真人定妆质感：** 中性灰无缝摄影棚背景，柔和三点式布光，各格曝光一致；保留真实毛孔、细微绒毛、自然发丝、皮肤纹理、布料褶皱与材质。无文字、无场景布景、无动态姿势、无美颜磨皮、无塑料皮肤或 CG 感。作品明确采用二维或三维风格时保留其既定画风，仅沿用布局与一致性要求，不擅自转成真人。

### 复用、验收与输入

按「工具技能」查询已有素材，并加载「媒体处理与剪辑」的文件读取附件实际查看图片，核对本次用途、角色身份与造型，不仅凭文件名、提示词或生成成功状态判断。当前上下文中已看过且未变更的图片无需重复读取。符合配方的四区板或结构图直接复用，沿用原资产引用；无法查看时说明尚未核验，不自动重生成。

只有设定时，按本次已确定用途准备素材；已有局部参考时保留脸与造型，只补下游确实缺少的部分。选角是形象待定时的可选步骤，获确认的单幅选角图作为制作四区板的身份依据。

按上表对应任务验收，四区定妆板逐项核对上述配方。结构图检查同尺度、完整正侧背与几何对齐；临时状态写清从哪场开始、持续到哪里，并在相关视图中保持一致。

视频输入中明确每张素材用于身份、服装还是结构。使用组合图时说明各视图属于同一角色，成片不展示整板，也不复制成多个人。身份参考不等于视频首帧；首帧另按镜头构图制作。人物参考整板输入。

## 图片名称要帮助选图

节点标题，以及工具技能给出的 `photos.name`，用来区分同一对象的图片。没有给出的名称字段不补造。新增、生成采用或整理本次图片时，结合实际查看的内容命名；已有准确名称保留，不全库重命名，不仅根据提示词把未核验的成图命名为成功结果。

- 人物优先写“造型或状态＋视角或用途”，例如“常服｜正面全身”“常服｜侧脸特写”“冬装｜背面”“雨后湿衣｜半身”。组合图写清包含什么，例如“常服｜正侧背三视图”“礼服｜四区定妆板”。只出现一种造型时可简化为“正面头肩”。
- 场景优先写“空间部位＋光照或状态＋观察方向”，只保留区分图片所需的信息，例如“正门｜夜景｜街对面朝府门”“凉亭｜夜景｜园中朝亭内”“车厢｜灯下｜前挡板朝车尾”。同一地点的反向图应能凭名称区分，不能都叫“场景图”。
- 不用空名称、“图片1”“参考图”“高清图”或单独重复人物、地点名作为新图片名称。不把资产 ID、模型名、时间戳或完整提示词塞进名称；确有多个相同用途的候选时才加简短方案区别，不用编号代替用途。
- 名称只陈述已确认的信息。看不清服装、方向或状态时使用能确认的用途描述，说明核验缺口，不编造方位或剧情事实。名称是选图线索，不能代替查看图片。

先给图片节点起能辨认对象和用途的标题，例如“江小白｜定妆四视图”“镇北侯府正厅｜场景”。结果采用后，节点标题和工具技能所给图集中的名称都按实际资产核对。图集读写按「工具技能」的分镜与媒体节点附件执行，保留其他图片、既有名称和顺序；名称不画进图片。

## 风格参考

风格参考提炼可见选择：主光方向与软硬、明暗反差、主次色、材质、线条或颗粒，而非只搬“悬疑感”“治愈感”等标签。例如借鉴冷调楼梯间时，可提取青灰环境光、侧后方亮区与湿地反光；借鉴自然光室内时，可提取窗边柔光、较低反差和木材质感。参考中的雨衣人物、建筑布局或陈设不因此成为本剧事实。项目已有风格时沿用其视觉方向，按场景调整实际光源，不给每张图套同一灯光。

## 让参考各司其职

写清每张真实参考允许继承的内容和不能带入的内容。身份图可控制面貌和体态，场景图可控制空间，风格图可控制色光与材质；不要让风格图中的陌生人物、服装或标牌混进本剧。图内有多人或多个物件时，用位置及可见特征明确目标，不能默认选择居中者。引用和绑定按「工具技能」执行。

按本镜画面实际会出现的内容选择参考，不按片段所属范围套用固定组合。码头一场的镜头里出现渡船、门外镜头里看到马车或宅门时，这些会入画的大件也需要已确认的依据；漏掉时模型会在每段各画一个不同版本。反过来，本镜看不见的人物和物件不必送入。

参考之间有冲突时先核对当前剧本状态和各自用途。例如人物设定图是干衣，而本场已淋雨，可保留身份并使用本场湿衣状态；不能让两张图同时控制同一套互斥造型。观察不到图片时说明依据来自用户描述或仍待检查，不声称已比对。

道具、招牌和屏幕上的字按剧情需要选择准确可读、仅保留不可读图形、空白或后期添加。需要可读时写明原文和位置，不同时全局要求“禁止文字”；采用后期方案时保留承载区域，并把确切文字及合成工作放在交付说明中。依赖文字的剧情信息须在最终画面可见，不能把空白图当作已经交付证据。

输入参考本身也要检查编号、字幕、标牌和其他无关字形。发现与目标冲突的内容后，图片制作任务需裁切、清理或更换参考；提示词修改任务列出待处理项。仅在 prompt 中加“不要文字”不能证明这些内容已去除。

## 首尾帧与分镜拼图

首帧落实该镜起点，尾帧落实已确定终点；尾帧不能另创一个不同的持物、位置或人物状态。每张图分别核对人物朝向、视线、手位、道具状态和光向，不能把动作结束后才出现的结果提前画进首帧。是否需要尾帧由本次生成方式决定，不为凑齐而制作。

如果既需要人物／场景／道具参考，又需要原生首帧或首尾帧约束，先用这些参考合成正式关键帧，检查人物身份、服装状态、持物、空间关系与构图，再将确认后的单张画面送入视频模型。正式帧应是干净的实际取景，不把人物设定组合图、九宫格拼图或占位示意直接当作首帧。已有准确画面可以直接复用，不为每段额外生成图片。绑定后的实际发送角色与边界能力按 [模型能力](model-capabilities.md) 核对。

复杂多镜头可用分镜拼图先比较构图和顺序。每格按最终视频画幅安排主体，整张拼图的画幅不等于单格画幅；每格呈现一个可冻结的时刻，动作过程与时长在对应 Shot 中表达。先核对实际图片里的空间和人物，再作为参考，文字说明正确不能抵消图中站位错误。

拼图是审核或顺序参考，不直接当视频首帧。需要首帧时提取或重作相应单格，去掉审核用编号、边框和注释；需要把整张图用于参考时，先确认模型支持相应输入，说明只借镜头顺序与构图，画面不展示整张网格。不能据此保证模型逐格切镜，仍需核对时长和实际结果。

## 局部修改与交接

局部改图说明“目标区域 → 可见变化 → 保持项”，交付说明再列出受影响的片段。例如用户要求右袖淋湿时，可以写：

> 仅让人物右袖肘部以下呈浸湿后的深色，布料贴近手臂，不增加破损。保留面貌、体型、衣服剪裁、左袖干燥状态、手持物、构图及原有光向。

原图和目标区域须能从实际输入确认。这是修改意图，不是已经完成改图；更换参考后，检查引用它的后续片段是否仍与剧情状态一致。

采用图片前观察身份、造型、空间、道具和文字是否符合用途；有明显漂移的图先修正，不继续作为基准传播。多场同时换脸时先查共享人物图及其绑定；只有一场异常时先查本场输入和提示词。仅写完图片提示词时，报告“待生成／待检查”，不宣称图片已可用。
