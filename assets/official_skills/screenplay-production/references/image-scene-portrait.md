# 人物场景图、复杂姿态与镜面构图

用于编写人物与环境同框的正式静帧，重点解决造型呈现、肢体支撑、衣料随姿态响应以及镜面反射空间。

## 完整人物场景图：把细节连成关系

先确定用途、主体数量、视觉风格与观看重点，再按以下 6 层将相关细节写成因果联动（例如手臂撑桌同时写接触位置、袖褶走向与压影），避免各自孤立成堆叠形容词：

| 画面层 | 正文需要交代的关系 |
|---|---|
| 人物与妆发 | 年龄、面部结构、当前神态与视线；发型收束位置、发尾落点与饰品固定点，交代遮挡还是露出肩颈与耳领 |
| 服装与装饰 | 内外层次、领肩腰线与固定点；材料厚薄、透明度与受光特性（如缎面宽亮带、哑光褶谷、金属窄高光） |
| 姿态与接触 | 躯干朝向、重心与支撑点；用**人物自身左右**标明手脚，写出接触面、压褶与压影，以及头颈视线是否协调 |
| 环境与空间 | 前中后景与相对尺度；家具/通道是否足以容纳该姿态，人物与道具之间是接触还是留有间隙 |
| 光色与调性 | 光源方向、冷暖与软硬、亮暗区分布；主辅色面积与区分，与生效风格配置保持协调（已注入风格不重抄） |
| 取景与焦点 | 相机高度、方向、构图重心与景别边界；明确焦点所在及前后景虚化，确认关键肢体与细节都在画内 |

**结构演示（人物+支撑+材质关系，按实际作品画风补入风格）**：

```text
夜间书房，横向半身中景，只有一位年轻男性学者靠坐在宽书桌前。他侧身面向右侧高窗，头部微转向镜头，神态沉静，视线平视前方；深棕微卷短发在耳侧留出间隙，使白衬衫立体领口与银质领针清楚可读。
左前臂平放在深色木桌面支撑上身，深灰羊毛外套右袖自然垂至腕骨，左袖因曲肘在肘弯处堆出横褶；右手翻按桌上一本敞开的皮面笔记本，手背与腕部接触纸页处有短而实的压影。高窗冷光从右上方照亮眉骨、发缘与皮质封面窄亮带，书桌左角台灯提供柔和暖光补足外套绒面层次。焦点落在双眼与翻开的书页，前景桌面边缘微柔化。
```

**成稿与看图核对**：对照需求核对人物数量、手脚左右、支撑承重、接触压影与焦点；缩略先看轮廓和视觉焦点，再放大看五官、手指与材质边缘。保持生效风格配置指定的渲染质感、光学效果与装饰密度，不靠堆画质词代替设计。

### 不同画风的视觉落点（无系统风格时按需补入）

已有系统生效风格时，风格前后缀由应用在生成前自动注入，正文只写人物结构、光源方向与材质差异；**仅在未配置风格（或写无注入草稿）时**，按目标美术方向把画风落成具体的媒介、肤眼处理与受光质感：

| 目标画风 | 媒介表现写法 | 皮肤、眼睛与衣料受光处理 | 局部示范（接在具体人物动作后） |
|---|---|---|---|
| **写实电影摄影** | 实拍电影摄影质感、自然光学景深与空气纵深 | 皮肤保留毛孔、细微纹理与自然过渡；眼睛带湿润眼神光；衣料经纬纹理与磨损清晰 | `写实电影摄影质感，自然轻微颗粒；窗光在颧骨与深灰羊毛肩线落出柔和过渡，皮面封面折痕带微磨损高光。` |
| **二维插画／动画** | 明确画法（如手绘赛璐璐平涂、厚涂或水彩），强调线稿与色块边界 | 肌肤用干净色阶概括，不做毛孔写实；眼睛突出简化亮斑与虹膜层次；衣褶随主线条收敛 | `二维赛璐璐动画质感，干净细线稿配两阶明暗色块；暖光在脸侧与袖缘切出清晰亮边，阴影呈清透冷灰。` |
| **风格化三维／CG** | 三维渲染与可控表面粗糙度（不堆“8K/UE5”空词） | 按设定采用柔润次表面散射或定制偶感质感；发丝分组造型，哑光布料与金属高光反差明确 | `风格化三维CG质感，肌肤呈细腻次表面柔光、虹膜清透；粗纺面料呈哑光绒面，金属领针带集中窄高光，背景适度景深柔化。` |

## 复杂姿态与服装响应

复杂姿态容易悬空、穿模或丢掉衣物逻辑。写作时同时固定以下五点：

| 要素 | 写作写法 |
|---|---|
| 支撑与重心 | 标清哪只脚承重、哪只手/肘/髋接触承托面，身体与墙面或家具之间留出真实手臂/腿部空间 |
| 关节与错位 | 肩→肘→腕、髋→膝→踝依次连接；正侧面姿态通过前后腿错开或手脚错位避免重影遮死 |
| 衣物固定点 | 明确领口、肩带、腰带、系带或扣件固定在哪；外搭滑落或偏穿时写清由什么承托 |
| 张力与重力 | 弯曲内侧堆褶、外侧绷展，自由下摆按重力垂向地面；硬挺饰件（如腰结、肩甲）沿固定点保持形状 |
| 接触与材质 | 接触点写压褶、形变与短压影；同色皮肤、丝缎、薄纱与棉麻用反光宽窄与透叠分开层次 |

**关键句示例（侧面俯身支撑）**：

```text
侧面全身取景，模特面向左墙，左脚在前、右脚向后错开踩实，髋部微后移使背部前倾，双臂伸向墙面，掌根贴墙留出肩距。贴身缎面礼服侧缝随躯干倾斜绷展，腰前形成细密折褶；后腰系结固定在腰带处，自由飘带垂直落向地面，肘弯手套与掌根压墙处保留短而柔和的压影。
```

## 镜面与反射构图

先在空间上固定**真实主体、镜面位置与倾斜角度、摄影机视向**三者关系，再决定镜内看到什么：

- **同一主体同一状态**：明确房间内真实只有几人，镜内与真实主体同衣着、同姿态、同光线、同不对称左右，不额外长出肢体或第二人。
- **几何遮挡与视野范围**：沿“相机 → 镜面 → 被反射部位”核对视角——要通过镜子露出背面/后腰细节时，确保真实身体与前景物体不挡住镜面反射路径，且镜框上下足以完整框住要看的头脚区域。
- **环境一致**：镜中的门窗、灯具、墙角遵循同一房间位置，避免把相机和灯具画进镜内。

```text
横向室内全身像，只有一位立于中央的人物；相机位于其左前方四分之三侧，焦点兼顾正面面部与后方镜中腰背。人物右侧稍后立一面竖直落地镜，镜面向左前方倾斜以避开自身遮挡，透过镜框完整映出同一人物背面、后腰结构与地面鞋底。左侧主光与环境补光同步落在人物与镜内背影上，远处陈设适度虚化。
```

生成后若镜内缺部位，先调整镜面朝向与机位高度；若出现“真人和镜中像不对应”的多余人影，在提示词中收紧真实人数并点明镜内是“同一人物的背面反射”。
