# 视频生成提示词

## 写作原则

按“主体与场景 → 起始构图 → 动作过程 → 运镜 → 声音 → 结束状态”组织本段必需内容。角色与关键道具称呼稳定；参考图已承担的外观不反复重述，只补动作、姿态与状态变化；视觉风格落到光源方向、色温、质感与运动方式，少用空泛形容词，且不重复抄写系统已注入的风格（读取实际展开内容按「工具技能」）。

先写清关键因果：发力、接触、受力、重心变化、表情反应与揭示路径，不缩成抽象结果词；优先正面写期望画面与动作，不无故罗列“不跳/不退”否定词。

对白保留原话、说话人与口语语种，标明语气、语速与发声窗口（不翻成提示词语言）；音色与情绪按需要分层写清剧内动作声、环境底声与画外配乐。声音描述会驱动画面（写“铃铛撞响”就容易演出撞击），改动作时同步改声音；跨切镜对白须连续时不跨 Shot 重写整句。提示词内不混入工具调用、本地路径或“参考待绑定”等待办说明。

运镜与组合配方见 [镜头任务配方](shot-recipes.md)。

## 逐镜内容与成稿核对

围绕当前场内状态确定取景内可见人与物；无首帧图时由“起始画面”承担机位、景别、光位、站位朝向与视线落点；同场多镜可用场景固定物（如门窗或柜台相对位置）标定机位。

| 层次 | 正文要交代的信息 |
|---|---|
| 起始画面 | 可见人物与道具的位置、朝向、视线、持物、景别与光位（群体交代范围与队形，重要个体单列） |
| 动作与表演变化 | 起点 → 发力/接触/位移/反应 → 停顿或释放（动作细节能看清，不堆砌微动作） |
| 摄影机行为 | 机位、路径、速度、揭示谁及停点；固定镜头写明框内变化 |
| 声音与终点 | 说话人＋原话窗口、同步音效与底声/配乐；末帧构图、持物与位置交接状态 |

写完后按四项核对再压缩冗余：
1. **覆盖齐全**：原文动作、逐字对白与在场主体均已落点；
2. **可见可执行**：当前景别与窗口能看清动作且台词来得及说完；
3. **连续无冲突**：相邻起止、参考图与共用文本一致（若修改部分镜头或格式转换，复查原有事件、场面规模与末态未丢失）；
4. **贴近上限时**：先去重外观和重复装饰，仍超长再拆段，不删剧情核心。

## 按模型选择格式

同一型号在不同渠道的 `model_id` 写法不同，按运行时渠道模型列表查询返回的 `catalog_model_id` 路由专属格式：

| catalog_model_id | 格式附件 |
|---|---|
| `doubao-seedance-2-0-260128`、`doubao-seedance-2-0-fast-260128`、`doubao-seedance-2-0-mini-260615`、`seedance-2.0-fast` | [Seedance 提示词](seedance-prompts.md) 的 2.0 写法 |
| `doubao-seedance-2-5-260628` | [Seedance 提示词](seedance-prompts.md) 的 2.5 写法 |
| `MiniMax-H3`、`minimax-h3-fast`、`minimax-h3-max-turbo`、`hailuo-3-max` | [MiniMax H3 提示词](minimax-h3-prompts.md) |
| `kling-v3.0-pro`、`kling-v3.0-std`、`kling-video-o1`、`kwaivgi-kling-v3.0-4k`、`kwaivgi-kling-v3.0-turbo` | [Kling 提示词](kling-prompts.md) |
| `veo-3.1`、`veo-3.1-fast`、`veo-3.1-lite` | [Veo 提示词](veo-prompts.md) |
| `wan3.0-video`、`wan3.0-video-prime`、`wan-2.7`、`wan-2.6` | [通义万相提示词](wan-prompts.md) |

- 专属格式仅取代下文**通用 Shot 结构、时间写法与提示词语言**（台词原话永远不翻译）；内容完整性与连续性要求不变。
- `catalog_model_id` 为空、不在表中（如 `kwaivgi-kling-v4.0`、`kwaivgi-kling-video-o3-4k`、`alibaba-wan-2.5`、`hailuo-2.3` 等）或模型未定时，使用下方通用格式；换模型后按新格式整段重排，不局部打补丁。
- **引用语法唯一真源**：所有需要提及输入素材的位置，统一使用完整双属性标签 `<ref input_id="…" label="…" />`（两个属性均为非空值；应用提交时会按渠道替换为对应图片位号），严禁省略 `input_id` / `label` 属性的 `<ref>` 简写、也不要写成 `@图片1` 或 `<Picture 1>`。

## 通用镜头格式

- **单镜头片段**（或单人连续直拍）：不写片头总述，直接从 `Shot 1` 开始。
- **多镜头片段**（且存在参考图或系统风格未覆盖的**跨镜共用不变量**，如全段一致的环境基调或持久光位）：仅可按需在 `Shot 1` 前加 1–2 句 `本段共用锚点：……`；绝不提前剧透结尾变化（如雨停、倒塌），也不重复已绑参考或已注入风格。

每个镜头按顺序写（用于单个分镜节点正文；不把每个 Shot 新建成分镜；另 UI 快捷追加也会生成简式 `[起-止s] 节拍：`，正式完稿按本结构补全）：

- 镜头头：`Shot N（景别·角度·运镜·时长）`
- 区间：`【起-止s】`（从 0 连续相接，末镜终点等于生成总时长；通用格式支持 0.1 秒精度，**切换至仅支持整数秒的专属模型时，须将各镜区间重排为连续整数秒且总和等于配置时长**）
- 首帧：开场可见构图、主体与光位
- 节拍：`[起-止s]` 写本区间动作、表情、运镜及带语种/语气的原话
- 结束状态：末帧构图与持物交接状态

### 三镜头草稿示例（8 秒，`duration_ms: 8000`）

```text
Shot 1（中景·平视·固定·4s）
【0-4s】
首帧：夜间室内，暖色台灯从画面左侧照亮木桌。林岚在左侧，周明坐在右侧，两人隔桌相对。林岚右手食指按着桌上钥匙，周明双手停在自己一侧桌沿。
[0-2s] 林岚用右手食指把钥匙沿桌面推向周明，在桌沿内侧停住，指尖仍压着钥匙。
[2-4s] 周明看着钥匙没有伸手，随后抬眼看向林岚。房间安静，只听见钥匙擦过桌面的轻响。
结束状态：钥匙留在周明面前的桌沿内侧，林岚指尖仍按着它；周明抬头注视她。

Shot 2（近景·平视·固定·2.5s）
【4-6.5s】
首帧：切到周明近景，沿用上一镜左侧暖光，他看向画外左侧的林岚。
[4-6.5s] 周明压低声音用普通话问：“你真的要走？”语速放缓，句末停顿半拍。
结束状态：周明保持注视等待回应，双手仍未抬起。

Shot 3（特写·微俯拍·固定·1.5s）
【6.5-8s】
首帧：切到桌沿钥匙特写，沿用左侧暖光。林岚右手食指仍压着钥匙。
[6.5-8s] 林岚右手食指松开并退向画面左侧，钥匙留在桌沿；仅保留室内安静底声。
结束状态：钥匙独自留在桌沿内侧。
```

## 结合真实参考写作

修订提示词时按「工具技能」保护已有 `<ref input_id="…" label="…" />` 引用；参考互相冲突时先明确分工，不靠“全部保持一致”掩盖矛盾，缺失参考时先输出草案并在交付说明中标注缺口。
