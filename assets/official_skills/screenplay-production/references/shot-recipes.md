# 镜头任务配方

把已确定的镜头设计落成可拍提示词。已有设计直接沿用，不为套用配方改剧情或机位。

## 按任务读取案例

按当前镜头最难成立的一点选读案例；案例时长需适配实际模型，人物场景替换为本剧设定：

| 当前任务 | 案例附件 |
|---|---|
| 说话者与听者反打、对白跨切点延续 | [两人对白与跨切声音](examples/shot-dialogue.md) |
| 人与人递物、接住、释放或换手 | [交接物件与持有关系](examples/shot-handoff.md) |
| 摄影机移动显露被挡住的人或物 | [遮挡揭示与运镜参考](examples/shot-reveal.md) |
| 从已有片段**实际尾部状态**继续拍摄 | [按实际尾部状态续拍](examples/shot-continuation.md) |
| 进攻、格挡、逼退或反制（看清接触与受力） | [动作对抗：逼退后反制](examples/shot-combat.md) |
| 连续跟随人物，由身体反应引出环境 | [连续运动与揭示](examples/shot-continuous-reveal.md) |
| 角色动作差异、特效因果与高潮递进 | [风格化动作：破盾开路](examples/shot-stylized-action.md) |

> 本附件仅负责镜内镜头写法与状态衔接；跨独立生成任务的接缝设计与出入点裁剪不属于本附件范围（`shot-handoff.md` 只解决镜内交接，不负责片段拼接）。

## 从概括展开为可拍过程

“交锋、被逼退、冲破包围、完成交接”只是结果摘要；正式提示词沿着**“察觉或触发 → 接近与接触 → 受力与环境响应 → 停点与最终归属”**展开可见过程，并在对应时刻落入摄影机路径与声音。快节奏动作依然保留因果顺序，删去的是无效等待而非接触本身。

例如将“剑客被枪手逼退到柱边”展开为（完整对抗见 [动作对抗：逼退后反制](examples/shot-combat.md)）：
> 侧面全景纳入双方脚步、兵器与后方石柱。剑客听到侧后脚步后转身抬剑；枪手踏前直刺胸口，她侧移半步斜剑架开枪杆将枪尖拨偏；枪手前压顶住剑身迫她后退两步，肩背抵上石柱，持剑手仍隔开枪尖；摩擦声与踏水声从接触时刻开始。

| 需要呈现的过程 | 展开关注点（以 [连续运动与揭示](examples/shot-continuous-reveal.md) 为例） |
|---|---|
| 登高与站稳 | 重心脚落在哪级、手撑何处、相机保持几步距离并与人物同步减速 |
| 疲惫转为察觉 | 抬手擦汗 → 抬眼瞬间手停住、喘息打断（先给反应角度，先藏完整远景） |
| 观众看清目标 | 明确前景遮挡物，相机越过遮挡按近→中→远显露，人留在前景作尺度参照 |
| 结束与声音承接 | 定格构图与视线方向；喘息渐轻，环境底声渐清并延续 |

多人镜头逐一明确在场者位置与可见状态，近景只写景别内能看见的部位（头肩近景不强行交待鞋底）。

## 运镜对照表与可执行写法

确定目的、起止构图与触发时机后按表选用（英文标签仅供辨识类型，具体格式按所选模型适配）：

| 运镜类型 | 适用目的 | 提示词要点示例 | 常见失误 |
|---|---|---|---|
| 固定（static） | 观察等待、看清表演或证据操作 | 平视双人中景固定桌边；她推信过去他不接，双手始终入画 | 写成人物也冻结；既固定又跟拍 |
| 推近（push-in） | 注意力收向表情反应或核心细节 | 她停口后机位缓推，从腰上收至头肩停在抬眼反应 | 无触发无终点；裁掉关键手部 |
| 拉远（pull-out） | 揭示周边处境、孤立感或尺度后果 | 放下电话后平稳后退，从头肩拉至空荡候车室全景 | 穿墙后退；人物缩过头看不出关系 |
| 水平摇（pan） | 原机位转向另一主体或画外声源 | 闻敲门声原位右摇，从侧脸转至紧闭木门停住 | 混淆摇镜与横移；左右关系跳变 |
| 俯仰摇（tilt） | 原机位上下移动显露高度或手→脸 | 从握紧的手起摇，沿手臂仰至面部眼神停住 | 误写成升降；揭示物不在当前竖轴 |
| 横移（truck） | 靠前景视差绕开遮挡，揭示隐蔽物 | 机位右移，近景立柱左退露出门边站立者后停住 | 拿摇镜代平移；前景与后景粘连 |
| 跟拍（tracking） | 维持步距跟随位移与空间路线 | 保持左后两步背面中景跟随，人至楼梯口停则相机同停 | 不写相对距离与停点；无意越轴 |
| 弧线绕行（arc） | 切换侧面视角露出遮挡或双人格局 | 绕坐者沿桌外从左前弧移至右前，停在人门同框处 | 无意义绕整圈；路径穿桌穿人 |
| 升降（pedestal） | 改变相机高度揭示上下空间层次 | 相机由栏杆下升至栏杆上并微俯，纳入下层站台与主体 | 只调仰俯却称升降；升高构图不变 |
| 变焦（zoom） | 机位不动收放取景范围 | 停在走廊尽头渐推焦，由整窗收至窗内面庞 | 把光学变焦写成相机向前位移 |
| 手持（handheld） | 确认需要的临场感与贴近呼吸 | 手持头肩近景带轻微自然晃动，对准面部至说完停顿 | 过度抖晃糊掉主表演；同时要求死锁 |

组织成句时严格落实 **`起始构图 → 触发时机 → 路径与速度 → 揭示对象 → 结束构图`**：移动路径不得穿墙越桌；同一时间窗口不同时写冲突指令（需衔接转换时写明“先固定……待动作落定再缓推……”）；一镜只担一个核心运动意图，若机位调度挤占关键动作接触，优先简化运镜保住叙事动作。
