# 镜头任务配方

负责把已确定的镜头设计组织成具体提示词，包括运镜表达、主体动作、声音衔接与结束状态。整体拆镜、景别、切点、站位与连续性设计见 [分镜指南](storyboard.md)；已有设计时直接沿用，不因套用配方重新安排剧情或机位。

## 组织镜头提示词

先确定起始构图，再按发生顺序写主体动作与摄影机行为，将对白和声音放入对应过程，最后落到可观察的结束状态。摄影机何时开始、跟随谁、在哪里停，要与人物的实际行动对应。

需要具体运镜写法时查下表；需要完整片段时按任务选择后面的对白反打、物件交接、遮挡揭示或尾帧续拍案例。Shot 格式和模型专属写法统一由 [视频提示词](video-prompts.md) 维护，这里只提供组织方法与成稿示例。

以下是原创教学样例，时长仅示范节奏，均未实际生成；使用前匹配真实模型与输入，不把例子中的秒数当能力上限。范例假设人物及场景视觉设定已确定；没有参考时须补足真实外观，不能拿同名角色代替素材。

## 运镜对照表

根据已经确定的镜头目的、起止构图与运动意图，选择下表中的表达方式。适用目的只是参考，不把它当成必须使用某种运镜的映射。

提示词示例只展示摄影机行为，使用时替换为本场真实主体、空间与动作。英文术语用于辨认类型，实际写法按目标模型的提示词附件适配，不假定所有模型都同样理解这些词。

| 运镜类型 | 适用目的 | 起止构图 | 提示词示例 | 常见问题 |
|---|---|---|---|---|
| 固定（static / locked-off） | 观察、等待、保留表演；清楚展示操作或证据 | 相同机位、景别与取景方向，变化由人物或环境完成 | 平视双人中景，摄影机固定在桌边；她将信推过去，他保持不接，两人的手始终入画。 | 把固定写成人物也冻结；同时要求机位不动又跟随人物离开 |
| 推近（push-in / dolly-in） | 将注意收向人物反应或关键细节 | 双人中景或单人中景 → 目标近景，摄影机接近主体 | 她停下解释时，摄影机缓慢向前移，从腰部以上收至头肩，停在她抬眼后的表情上。 | 只写“缓推”而无触发与终点；推进过度裁掉关键手部；与变焦混用 |
| 拉远（pull-out / dolly-out） | 揭示环境、距离、孤立感或局面后果 | 人物近景 → 含环境与关系的中远景 | 他放下电话后，摄影机平稳后退，从头肩近景拉至空荡候车室全景，人物留在画面中央。 | 后退路径穿墙；凭空增加原场景不存在的空间；人物被意外缩得无法辨认 |
| 水平摇镜（pan） | 在同一机位把注意交给另一主体或画外信息 | 朝向主体甲 → 转向主体乙，摄影机位置不变 | 门外传来敲击声，摄影机在原位向右缓慢转动，从她的侧脸摇到紧闭的门并停住。 | 把转动机身写成横向移动；转向后人物、门的位置或屏幕方向不连贯 |
| 俯仰摇镜（tilt） | 沿上下关系揭示人物、物件或高度 | 下方细节 → 上方目标，或反向；机位高度不变 | 从他握紧的手开始，摄影机保持原高度向上仰摇，沿手臂移到脸部并停住。 | 把仰摇写成摄影机升高；揭示的部分不在当前空间关系中 |
| 横移（truck / lateral move） | 利用视差揭示遮挡后的信息，调整并列关系 | 遮挡构图 → 主体显露，摄影机沿左右路径平移 | 摄影机向右平移，近处门框逐渐退到画面左缘，露出一直站在门内的人；完整看见他时停下。 | 用摇镜冒充平移；被揭示者突然出现或移动来配合；前后景粘在一起 |
| 跟拍（tracking / follow） | 跟随位移，维持人物与环境的可读关系 | 起点的前、后或侧跟位置 → 人物停点附近，保持约定距离与景别 | 摄影机在她左后方保持两步距离跟随，维持背面中景；她在楼梯口停下时，摄影机随之减速停住。 | 只写“跟随”未说明相对位置；主体快跑与机位慢移却要求距离不变；无意越轴 |
| 弧线移动／环绕（arc / orbit） | 展示另一侧关系、遮挡或空间处境 | 主体一侧 → 明确另一侧，沿可行弧线移动 | 以坐着的人为中心，摄影机沿桌外侧从左前方移至右前方，保持中景，停在他与门同时入画的位置。 | 无目的绕满一圈；穿过桌子或人物；两人左右关系变化却未建立空间 |
| 升降（pedestal / crane） | 揭示上下层次或改变观看高度 | 低机位 → 高机位，或反向；说明俯仰是否随之调整 | 摄影机从栏杆下方缓慢升至栏杆上方，并略向下转动，最终让下层站台与她同时入画。 | 只改变仰俯角却称升降；升高后仍要求取景完全不变；为“大气”添加无关鸟瞰 |
| 变焦（zoom） | 从同一机位改变取景范围与主体画面占比 | 宽取景 → 窄取景，或反向；摄影机位置保持不变 | 摄影机留在走廊尽头，逐渐变焦收窄取景，从整扇窗收到窗内人脸，人物不向镜头走近。 | 写成摄影机向前移动；既要求机位不动又要求推进产生的空间位移 |
| 手持（handheld） | 经风格确认的现场感、身体不稳或贴近感 | 明确取景范围，可伴随已说明的跟随路径 | 手持头肩近景，保留轻微自然晃动；摄影机始终对着她的脸，等她说完后停留，不额外推近。 | 把手持等同于剧烈抖动；同时要求机位绝对锁定；晃动掩盖关键表演 |

### 把选定的运镜写成可执行描述

写清 **起始构图 → 触发时机 → 路径与速度 → 跟随或揭示的对象 → 结束构图**。固定镜头则说明固定的景别、方向，以及画内人物和环境如何变化。起止状态来自当前分镜或实际参考，不为实现运镜改写剧情、站位或素材内容。

- **区分摄影机与主体。** 人物可以向画外走而摄影机保持固定；需要跟拍时才说明跟随方向、相对距离和停点。摄影机绕过遮挡不意味着人物此时才看见对方。
- **保持空间连续。** 移动路径不能穿过墙体、桌子或人物；检查入口、出口、轴线与屏幕方向。确需越轴时，用可理解的移动或重新建立空间完成，不在下一画面悄悄交换人物位置。
- **处理指令冲突。** 同一区间不能既绝对固定又推近，也不能同时要求向左摇和向右摇。需要变化时写清先后，例如“先固定在双人中景，等她把钥匙放下，再缓推至双手与钥匙的近景”。
- **保留一个主要意图。** 跟拍时小幅转动机身维持构图、升高时调整俯角可以服务同一目的，不按动词数量机械判错；复杂运动挤占关键动作时，优先简化摄影机路径，不能让交接或对白消失。
- **按实际结果验收。** 检查触发、路径、被揭示信息和停点，区分摄影机位移、人物位移与变焦；写入焦段或机位数值不等于生成结果精确复现光学。术语适配见 [视频提示词](video-prompts.md) 中的模型附件入口，横移揭示的完整成稿见下方“遮挡揭示与运镜参考”案例。

近景只描述景别内可见的部位：头肩特写无需交代鞋底，全身退步不能只靠眼部特写展示。角色在场不等于入画；单人镜头把交流对象写成画外方向，确需展示听者时明确切镜或进画。

## 一、两人对白与跨切声音

原文：林岚问：“车到了，你还走吗？”周明答：“等他回来。”林岚看了他一会儿，垂下眼。

选择：前半句看说话者，后半句看听者，让反应先于回答出现。将整句分配到连续发声窗口，文字拼接后仍是原话；不要在两个 Shot 各写一次完整句子。

```text
Shot 1（近景·平视·固定·3s）
【0-3s】
首帧：夜间候车室，林岚坐在画面左侧，面向右侧的周明，周明肩部虚化留在右前景。顶部暖白灯照亮人物，窗外有低而平稳的雨声。
[0-1s] 林岚保持看向周明的视线，轻吸一口气，周明安静听着。
[1-3s] 林岚用普通话轻声说：“车到了，”语速自然，句子尚未结束，声音连续进入下一镜。
结束状态：林岚仍看着周明，正在继续同一句问话，人物位置与灯光不变。

Shot 2（近景·平视·固定·4s）
【3-7s】
首帧：切到周明近景，他看向画外左侧的林岚。机位保持在两人轴线同一侧，顶部暖白灯不变。林岚不在画面中。
[3-4.5s] 林岚在画外接着说完：“你还走吗？”这是上一镜问话的后半句。周明嘴唇闭合，听完才略微移开视线。
[4.5-5s] 周明停顿，视线回到画外左侧。
[5-6.5s] 周明用普通话低声回答：“等他回来。”语速平缓。
[6.5-7s] 周明说完，目光仍留在画外左侧。雨声连续，没有其他说话声。
结束状态：周明回答完毕，嘴唇闭合，仍坐在原处。

Shot 3（近景·平视·固定·3s）
【7-10s】
首帧：切回林岚近景，沿用第一镜的机位侧与暖白灯，周明肩部仍在右前景。
[7-8.5s] 林岚没有回应，目光停在周明脸上。
[8.5-10s] 林岚缓慢垂下眼，保持自然呼吸，两人不再说话，只有连续雨声。
结束状态：林岚低着眼，周明仍在原位。
```

验收：两句原话各出现一次，听者不跟着动嘴，回答在问话后，雨声不因切镜重启，林岚垂眼发生在回答之后。

若跨切处持续重说，可把整句问话留在第一镜，说完再切听者，同时重排各区间。若改为后期配音，说明新的声音制作任务，不把无声口型草稿当作已经交付对白。三人以上同样先明确当前发声者与画内听者，必要时单独给第三人的反应；不因人数机械拆段。

## 二、交接物件与持有关系

原文：林岚把封好的牛皮纸信封交给周明。周明接住，低头看着信封。

选择：交接时完整看见双方手部，接收者托稳后原持有者才释放。动作完成后再切反应，保留同一物件的朝向、封口和持有手。

```text
Shot 1（中近景·微俯拍·固定·5s）
【0-5s】
首帧：木桌旁，林岚在左、周明在右，机位容纳两人的手、信封与桌沿。林岚右手捏住封好的牛皮纸信封左侧短边，信封悬在桌面上方；周明尚未接触。场内左侧窗户照亮桌面。
[0-1.5s] 林岚将信封递向周明，右手始终捏住同一短边，信封不旋转。
[1.5-3s] 周明伸左手从下方托住信封右半部。林岚仍捏住左端，双方短暂共同持有同一个信封。
[3-4s] 周明左手托稳后，林岚松开手指，空右手退向左侧。信封由周明左手承托，不落回桌面。
[4-5s] 周明把信封收至胸前下方。只有纸张轻擦声和室内底声。
结束状态：完整信封在周明左手，林岚右手空置，退回自己一侧。

Shot 2（近景·平视·固定·3s）
【5-8s】
首帧：周明近景，完整信封仍在左手、胸前下方，位于画面下部。沿用同一窗户光源与人物轴线；林岚不入画。
[5-6.5s] 周明低下目光看信封，左手保持承托，不换手。
[6.5-8s] 周明停住，不拆封，不再次接物，保留室内底声。
结束状态：周明低头看着左手里的封好信封。
```

验收：先接触后释放，没有双信封、凭空换手、缩放或自动拆封；第二镜承接已完成交接。戒指、钥匙、细小零件需重新设计抓握部位与取景，不只替换名词。信封能托住，不代表细小钥匙适合相同手势。

失败改写：把“迅速递信、环绕两人、接过拆开阅读”改为固定镜头完成递交，再安排开封、阅读。若开封是原剧情，保留为后续镜头，不用删戏减少负荷。

## 三、遮挡揭示与运镜参考

原文：林岚停在走廊立柱旁，发现周明还站在门边。两人相望。

选择：周明一直在门边，立柱只挡住摄影机看向他的视线，林岚停步时已经能看见他。摄影机横移让观众看清她在注视谁，不把摄影机视野变化当成人物视线变化。若剧情要求人物也绕柱后才发现对方，需要另写人物的可见移动并更新站位。

```text
Shot 1（中景·平视·向右横移·6s）
【0-6s】
首帧：夜间走廊，林岚停在左前景，身体朝向走廊尽头。中右侧前景立柱挡住后方门边区域，门框一角露在柱边。顶部暖白灯照亮走廊，地面与墙面位置稳定。
[0-1s] 林岚停住脚步，望向门边，目光停住；从摄影机位置尚看不到她注视的人。只有低声通风声。
[1-4s] 相机平稳向右横移，近处立柱相对画面向左移开，逐渐露出后方门边的周明。周明原本就在那扇门旁，双手自然垂下，没有从别处走入。林岚留在左前景。
[4-5s] 周明完整露出时，相机减速停下，观众看清林岚一直在注视他；周明看向林岚。
[5-6s] 两人保持相望，自然呼吸。构图同时容纳左前景林岚与右后景周明，无对白或新增音效。
结束状态：立柱位于画面边缘，不再遮住周明，两人保持场内位置并目光相接。
```

若有实际运镜参考，额外说明它只控制横移方向、速度变化与停点，人物、服装、走廊和声音仍由本场决定；引用用已有真实标签。参考本身是环绕或推进时，不可仅凭标题把它描述成横移。没有参考时，上述独立空间和运动描述仍须成立。

验收：前景相对位移逐渐向观众揭示人物，未以变焦、溶解或换场替代；门柱位置不跳变，林岚所在位置确实能望见门边。若人物突然出现，先看首帧是否把本应被遮挡的位置画成了完整可见空地，修实际输入，不只追加“禁止凭空出现”。

## 四、按实际尾部状态续拍

原计划：周明取下纸箱，放到桌上，下一段打开纸箱。

教学假设：已采用视频实际结束时，周明双手托箱站在桌边，箱底尚未碰桌；尾部回看显示相机已停，只剩室内通风声。这里不是对任何用户视频的观察结论。真实使用需分别检查画面和声音，单张尾帧不能证明相机或声音已经停止。

选择：先补完尚未发生的落桌，再开盖；不能把预定终点写成实际起点。下面假设真实尾帧已绑定且与描述一致：

```text
Shot 1（中近景·平视·固定·7s）
【0-7s】
首帧：周明站在木桌后，双手托着未封胶带的纸箱，箱底在桌面上方。构图容纳上身、双手、完整纸箱与桌面，沿用已提供尾帧的姿态、暖白顶灯和取景。
[0-2s] 周明缓慢下放纸箱，直到箱底接触桌面，发出一次轻闷响。箱体稳定后，双手才离开箱底。
[2-3s] 双手移至箱顶对合的两片纸盖边缘，纸箱保持在桌上，不再次抬起。
[3-5.5s] 周明将两片纸盖沿原折线向左右掀开，箱体不变形，固定镜头完整看见开盖过程。
[5.5-7s] 周明松开箱盖，双手停在箱体两侧，没有伸手取物。通风声延续，纸板摩擦声结束，无对白或音乐。
结束状态：纸箱放稳在桌面，两片顶盖打开，周明未取出箱内物件。
```

如再提供目标尾帧，它应对应箱子落桌、盖子打开，不能换箱体尺寸、桌子、人物或机位。端点图之间仍保留“接触桌面 → 释放承托 → 手移至盖边 → 沿折线打开”的可见过程。

验收：不从架上再取一次箱子，不跳过落桌，不悬空开箱，不抢先取出后续物件。若实际结果仍未完成开盖，下一段采用结果前先判断是否可接受，不因为已有下一段草稿就假定动作完成。连续声场需在拼接处试听，不能由首尾帧相似推断。
