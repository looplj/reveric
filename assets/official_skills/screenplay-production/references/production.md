# 制片流程

## 制作单位与操作边界

界面的“分镜”是一条图片或视频制作内容，一次生成可含一个或多个 Shot 镜头；“视频”是独立制作节点，不自动进入成片。修改某条分镜时原地编辑；改其内部某个 Shot 时只改对应片段文本，不另建分镜。

分镜读写、排序、输入绑定、提交生成、采用与导出遵循「工具技能」对应附件；本附件只负责制片规划与交付标准。画布坐标不代表播放顺序，导演台布景也不代表成片。

## 从创意直接制作短片

没有现成剧本且用户授权原创时，先用简短方案锚定三件事：观众主看点、中间变化，以及末尾靠哪个可见结果兑现。把抽象目标（如压迫感、反差）落成具体观看体验（如以弱胜强的反制、由局部误判引向全景揭示）；确定能支撑该体验的光色、景别与声音强弱，再规划片段数与时长。已有剧本时严格以原文为依据，不擅改剧情事实。

## 从剧本拆分镜

1. **清点依据**：读取本次范围剧本与已有分镜，按工具技能核对依据、已采用图片与已绑定输入；分清哪些可复用、哪些待核验或缺失。仅文本计划或未采用结果不算就绪依据。
2. **覆盖原文**：按顺序列出必须保留的动作、逐字对白与揭示，映射成片段及其 Shot，确保无遗漏或重复；一镜可承载多件小事，不机械一句一镜。
3. **划分边界与段长**：先按下文设计段间接缝，再按 [模型能力](model-capabilities.md) 确定单段时长与拆分边界；不在短窗口内强塞加速对白，也不把上限时长当成必须填满的配额。
4. **规划与备齐输入**：写清每段起止画面与所需素材；缺图时可先输出标记“参考待绑定”的草案，实际提交前必须按工具技能完成备图、查看与绑定。
5. **写入、核对与回读**：按工具技能写入指定范围，回读确认顺序、总时长与相邻起止；局部任务只改指定目标。

### 先设计段间接缝

提交前为每组相邻片段明确：前段停在哪个动作阶段、后段从何处接起、以何种方式切换，以及依赖哪些画面或声音依据。

| 衔接要求 | 制作安排 | 下一段的依据 |
|---|---|---|
| 连续物理动作（如递物、接住、收起） | 优先放同一次生成内（内部可切 Shot），不在接触或受力中途硬拆 | 同段内连续动作过程；必须跨段时改在“握稳释放后”切开 |
| 正常切镜（正反打、反应、换景别） | 共用已确认人物、服装与场景参考，各自安排起始构图 | 明确的站位、视线、运动方向与剧情状态；不停留在抽象“硬切” |
| 紧接上段结尾画面或连续运动 | 等前段生成并看片核对后，再用其可用出点截图或末态准备后段 | 前段**实际**视频／画面与状态；不同时并发盲猜前段结果 |
| 跨段维持同一空间与多人站位 | 按下一镜真正需要的信息选交接画面（需要看布局选全景，看动作接触用近景） | 实际画面中可核对的站位、持物与环境依据 |
| 精确动作续接难以稳定实现 | 改用反应镜、关键物件特写或空间重定位切点，保留必需事件 | 可独立成立的镜头与一致状态；如降低原连续要求需向用户说明 |

接续画面与角色／道具参考按工具技能与 [模型能力](model-capabilities.md) 组合使用；选取出点近处画面作下段首帧时，挑选动作完成、画面清晰的一帧，不死取文件最后一帧。前段实际偏离预定末态时，同步修正后段起点。

多个分镜共有的稳定舞台或阶段设定可放共享文本节点（如阵营光色、雨夜阶段特征），避免与已注入风格重复或与阶段末尾变化（如雨停）冲突；局部变化留各镜正文，修改共享节点前评估下游影响。

### 替换已有镜头

补拍剪回成片时，查看保留的前后实际镜头来确定必须继承的站位、持物与陈设（不从旧文本重推）；换机位可以改变背景尺度与遮挡，不能重排陈设或重置状态。新结果核对前后双接缝后才算就绪，具体参考选图按 [图片资产与参考](image-references.md)。

## 排清制作依赖与提交顺序

按“规划与接缝设计 → 准备与查看共用图 → 绑定参考 → 按需制占位与正式首帧 → 写提示词并生成”推进；依赖未核验共用图或前段尾帧的任务保持串行等待，其余输入就绪的独立任务可并发执行。

| 环节 | 产出要求 | 何时推进 / 返工 |
|---|---|---|
| 原文覆盖 | 关键事件、逐字台词与揭示顺序映射表 | 检查漏戏、重演与提前剧透 |
| 共用视觉依据 | 按 [人物参考用途](image-references.md#按下游任务选择人物参考) 准备人/景/物图 | 必须实地看过图像与采用状态再往下推进 |
| 占位图／预演（按需） | 导演台或斜俯视/顶视站位图厘清走位与轴线 | 按 [分镜指南](storyboard.md) 排查遮挡、越轴与够物合理性；不把简模当终稿 |
| 正式首帧（按需） | 符合本镜机位与起始态的合成关键帧 | 存在剧透手势或构图错位时先重画首帧 |
| 提示词与输入 | 完整 Shot 文本、配置与真实 `<ref>` 绑定 | 缺图时标“参考待绑定”；写入按工具技能执行 |
| 接缝与成片核对 | 实际视频与音轨抽检及邻接复核记录 | 共用图改版时记录受影响分镜并复查，不盲目整批重出 |

需要提前试拍验证高风险机制（如复杂对抗、罕见特效或关键长镜头）时，先试拍最决定成败的镜头并明确试拍只证明了哪几项指标。对白窗口按语速分开可重叠行为（边走边说）与独占动作（递毕开口），不拿总字数除固定语速充当实测音频。完整全流程示范见 [整场制作案例](examples/scene-example.md)。

## 写后核对与接缝检查

- **文本与配置自检**：按工具技能合并审阅共用文本、风格与本镜正文，确保不冲突、未重复；若提示词含时间区间，核对区间连续且总长与工具配置一致；用工具技能核对范围总时长（不口算估算），时长差距如实向用户交代原因，不靠无意义拉长空镜或删戏凑数。
- **跨段接缝实际复核**：相邻两段均有视频产物后，即用「媒体处理与剪辑」读取出点/入点连续画面与声音（不能只看首尾静帧）。发现多演收势、重复起手时，优先**成对调整剪辑出入点**；无法靠裁剪消除缺失动作或矛盾站位时，按保留画面约束补拍缺失过渡并重查双切点。

## 质量验收、诚实交付与返修

按三个层次给出明确事实结论，不把仅检查了文字或静帧汇报成完整通过：

| 层次 | 关注点 | 最低事实依据 |
|---|---|---|
| 内容成立 | 人物、道具、关键事件顺序是否齐全且只演一次 | 连续抽帧或看片核对顺序与归属 |
| 镜头成立 | 接触、受力、反应变化、镜头揭示与口型节奏是否成立 | 连续视频看动作速度与力度，音频看口型与声画匹配 |
| 成片成立 | 转场后事件是否连贯、高潮是否兑现、声音是否协调 | 实际拼接时间线与前后邻接检查 |

- 交付严格区分“提示词草案 / 参考待绑定 / 已提交待结果 / 仅静帧已查 / 连续视频与音轨已核对”。
- 发现具体故障后（如时间点、预期 vs 实测偏差与保留项），先定位根因再按 [结果诊断与改写对照](troubleshooting.md) 单变量修正，不在无新依据时盲目重复生成。
