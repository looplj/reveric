# 制片流程

## 制作单位与操作边界

界面的“分镜”是一条图片或视频制作内容，一次生成可含一个或多个 Shot 镜头；“视频”是独立制作节点，不自动进入成片。用户说“改第几个分镜”时先定位该条内容；说“改 Shot 2”时只修改其提示词中的对应镜头，不另建分镜。

制作设置、归属、排序、素材输入、生成、采用与导出遵循「工具技能」对应附件。本附件只负责制作安排。画布位置不代表播放顺序，导演台布景也不等于已生成视频。

## 从剧本拆分镜

1. 读取本次范围的实际剧本、已有片段，以及人物、服装、地点和关键道具的已确认依据。按工具技能核对依据、已采用的图片和已绑定输入，简要说明哪些可复用、哪些待核验、哪些缺失。节点存在或 prompt 非空不能证明图片已就绪，未采用的图片也不能当作可用依据。已有同内容片段时原地修订，避免重复创建。
2. 按原文顺序列出本次必须保留的动作、逐字对白、揭示和转折，再分配给片段及其 Shot；范围较大时可用简短的“原文事项 → 片段／Shot”清单核对覆盖。每段有明确起点、主要变化与可交付终点，重要对白和事件不因拆分而漏掉或重复；一镜可以覆盖多个事项，不要求一句一镜。
3. 先按下文的接缝方案选择生成边界，再按实际可用时长、输入方式与动作负载确定段长。一次生成可以包含多个 Shot，换景别不等于要新建生成任务；不能为合并而加速对白或删掉关键过程，也不要把时长上限当成必须填满的配额。
4. 明确每段的开场与结束状态，以及需要的角色图、场景图、首尾帧或已有视频。只拆分镜或写提示词时，缺素材可以先写草稿，但应在开始前说明缺口，交付标明“参考待绑定”。实际制作任务按下文的依赖顺序准备并核验输入；不能把素材计划当成已绑定输入，也不能默认改成纯文本生成。
5. 按工具技能的分镜与媒体节点附件写入 title、prompt、duration_ms 及已确定的配置。创建后用返回 ID 继续操作，不另建普通画布节点。任务覆盖用户指定的范围，局部任务只改目标范围。
6. 回读本次结果，核对工具技能规定的顺序、总时长和相邻衔接。交付说明实际完成的分镜与尚未完成的素材、生成事项。

### 先设计段间接缝

提示词中的“保持连续”只表达目标，独立生成不会仅凭这句话继承上一段的实际状态。先确定两段如何连接，再准备输入和安排提交；串行本身也不能保证连续。

| 衔接要求 | 制作安排 | 下一段的依据 |
|---|---|---|
| 完整动作连续发生，如递物、接住、收起 | 尽量放在同一次生成内，内部可以切换 Shot | 同一次生成中的动作过程；避免在接触、受力或交接中途硬拆 |
| 正反打、反应或换景别，允许正常剪辑 | 共用已确认的人物、服装和场景参考，按各镜头准备起始构图 | 明确的站位、视线、运动方向、持物与剧情状态；不能只凭共用人物图假定空间一致 |
| 从上一段结束处紧接动作与画面 | 先检查上一段实际结果，选定可用的接续画面，再准备下一段输入 | 实际画面或视频以及已确认的动作状态，不能拿计划终点代替 |
| 无法可靠实现精确接续 | 调整切点，以反应、物件特写或重新交代空间的镜头连接 | 可独立成立的镜头和一致的剧情状态，保留必须看见的关键动作 |

范围内有两段以上独立生成时，提交前为每个相邻边界写明它属于上表哪一种，以及下一段以什么为依据。原文或用户要求下一段承接上一段的结尾画面，或动作跨过边界不中断时，属于“从上一段结束处紧接”：后一段依赖前一段的实际结果，等前一段生成并检查后再准备输入，不与它同时提交。要改按正常切镜处理时，先向用户说明代价，不自行降级。

接续画面与人物、道具参考不是二选一。按 [模型能力](model-capabilities.md) 和「工具技能」核对接续画面在当前型号下可用的输入方式，再按本段更难保持的一项选择；不因某一种模式不发送其余参考，就认定只能放弃接续。

使用上一段末尾画面作为下一段首帧前，先核对清晰度、姿态、持物与构图。单帧只能提供可见状态，不能完整传递速度、运动趋势与声音；首尾画面相似也不能证明接缝自然。优先在动作完成或可剪辑的位置拆分，避免把运动中途的偶然姿态当作稳定起点。

例如“甲把钥匙交给乙，乙藏进衣袋”，优先在一次生成里完成交接与收起。必须拆分时，可在乙已握稳钥匙后切到乙的反应或收钥匙特写；下一段从钥匙已在乙手中的状态开始，不重演递钥匙，也不省略关键交接。

需要参考输入时，按 [模型能力](model-capabilities.md) 核对实际可用的输入方式；正式关键帧准备见 [图片资产与参考](image-references.md)。获取实际视频画面与绑定输入按「工具技能」执行；生成后的接缝检查见下文“相邻结果就绪后检查接缝”。

用户要求统一规格时，核对指定范围内实际保存的配置与提示词；仅修改文字不能据此断言视频已生成、结果已采用或质量已验收。

多个分镜共用的人物、场景或风格描述可以写进文本节点，并连接到这些分镜；只影响单个分镜的动作、对白与细节直接写入它的提示词。文本连接和引用标签按工具技能执行，修改前核对受影响的下游范围。

## 先把制作依赖排清楚

整段制作按“拆镜与素材需求规划 → 复用或补齐共用图片 → 查看、采用并绑定参考 → 按需准备占位与起始构图 → 完善提示词并生成视频”推进。需要的共用图片仍在生成、待核验或未绑定时，不提交依赖它的视频任务；独立且输入就绪的内容可以继续。用户明确选择纯文本生成或无参考试拍时，按该范围执行并说明连续性风险。

人物参考的选择、复用与命名按 [图片资产与参考](image-references.md) 执行；占位图制作与核对按 [分镜指南](storyboard.md) 执行。

| 环节 | 要得到的具体结果 | 何时继续、何时返工 |
|---|---|---|
| 原文覆盖 | 关键动作、逐字对白、揭示顺序及各自承担的片段 | 核对遗漏、重复和提前泄露；剪辑表达可以变化，剧情事实不能暗改 |
| 共用视觉依据 | 按 [人物参考用途](image-references.md) 选择的身份、服装或结构素材，以及场景布局、道具与状态 | 核验图片内容、当前采用结果及有区分度的名称；满足任务的四区板、结构图或场景道具图直接复用，仅补实际缺口 |
| 占位图／预演（按需） | 按本分镜与动作起点，用导演台或 45° 斜俯视站位图表达空间关系 | 按分镜指南核对本次站位与空间关系，不以静帧证明连续动作 |
| 首帧（按需） | 符合本镜实际景别与机位的起始画面 | 人物够不到物件、关键手部被挡或反打越轴时先调整；占位示意的俯视角与简化人形不直接作为正式首帧 |
| 本段提示词与输入 | 完整 Shot、时长、声音及相符的真实参考 | 有文字方案但未绑定输入时只算草稿；配置查询与写入按内置操作契约 |
| 生成与核对 | 实际结果以及是否满足本镜的证据 | 逐段核对实际结果与预定接缝，不以一次成功保证全部范围 |
| 衔接与采用 | 相邻片段的实际起止状态、声音和采用结果 | 相邻结果就绪后按下文检查接缝；修改共享参考时重新检查受影响的下游片段 |

按依赖组织工作，不把制作顺序误当播放顺序：同一场景、同一光照和造型的图片可集中准备，播放顺序以工具技能为准，不把画布坐标当成播放顺序。共用图更新后，记录哪些分镜仍引用旧状态、哪些需要重看，不自动重生成全部内容。

### 并发与串行提交

先确定上述接缝方案，再按实际输入依赖安排提交，播放顺序不决定生成顺序。

- 接缝所需输入已经核对、就绪，且互不依赖生成结果的任务可以并发；共用同一套已确认参考不构成串行依赖，接缝方案要求承接前段实际结果的除外。
- 需要其他任务产出的图片、接续画面或实际动作状态时，只等待对应的前置任务。检查其结果、准备并绑定所需输入后继续；其余独立任务照常推进。
- 用户要求先试拍时，先完成试拍并检查结果，再推进批量制作。

后台提交后的查询、等待与防重复提交按「工具技能」及「媒体处理与剪辑」的对应附件执行。

规划时长时，将实际或估计的台词发声、必须独占的动作、反应和可重叠部分分开。例如“边走边说”可以重叠，“等递物完成才开口”不能重叠；停顿需有叙事用途。不要把台词字数除以固定语速当成已经测量过的音频。跨独立生成尽量在完整语义或动作阶段后拆开，避免一句话的音色与节奏难以衔接。

完整工作示例见 [从原文到制作交付](scene-example.md)；不要求每次交付都使用同样数量的表格、素材或镜头。

## 写后核对

指定范围拆完分镜后，按本次范围读取视频分镜，用 Codemode 求和计划时长并保留缺失项数量，再与用户说明或作品智能体规则中的目标时长对照；不口算改写工具返回的合计。明显偏短或超出时，向用户说明差距，以及它来自剧本内容量还是拆分方式；不靠拉长镜头、加空镜或删戏来凑时长。

分镜配置和提示词中的时间区间属于计划值，不能作为正文实际耗时的证据。使用试读、配音或视频校准时，先确认对应的正文版本和覆盖范围；部分内容的时长不能代表全部范围。即使片段总时长符合目标，也要核对对白与动作能否在各自窗口内完成。

- 制片修改后回读片段：检查是否覆盖指定原文、顺序是否符合工具技能、对白是否说得完、相邻起止状态是否衔接，以及 ref 标签是否原样保留。采用带时间区间的提示词时，再核对区间连续且总长与 duration_ms 一致。
- 换模型、段长或生成方式时，同时核对受影响的配置与提示词；仅改字段但正文仍沿用旧时长，不算完成。
- 区分“已写入片段”“参考待绑定”“待生成”和“实际结果已核对”。工具没有返回任务或视频结果时，不声称已生成、已采用或已导出；用户反馈失败时先定位配置、参考或内容问题，不把修改提示词当成重新提交成功。

## 相邻结果就绪后检查接缝

相邻两段都有生成结果后，就用「媒体处理与剪辑」检查前段结尾与后段开头，无需等全部范围生成。按预定的连续动作、正常切镜或时空转换，核对动作、持物、站位、运动方向和声音衔接；正常换机位不要求两侧构图相同。具体读取、提帧与预览操作遵循该技能的镜头衔接检查流程。

发现非预期跳变时，先调整切点或剪辑连接，保留剧情所需的动作与对白；仍无法衔接时，再针对问题片段返修。修改切点、替换或重新生成片段后，重新检查受影响的前后接缝，其余独立任务继续推进。

按相邻片段记录检查结果与未解决问题。未经实际检查，交付时标明“接缝待检查”；只检查了静帧或未能核对声音时，说明实际检查范围和待核对项，不把画面相似当成动作与音频连续。

## 看结果再返修

区分提交失败和画面不合要求。没有生成结果时先按操作契约核对任务状态、配置和输入；有结果时观察实际文件，不拿封面或提示词代替视频检查。按本段需要核对事件是否按顺序发生且只发生一次，主体与道具是否保持，空间与动作方向是否接得上，对白和声音是否属于正确人物与时刻，以及输出规格是否符合要求。只看静帧不能证明动作和口型正确，也不能证明没有声音。

为每个实际问题记录片段、发生时刻或帧、预期与观察差异，以及可以保留的部分，再按 [结果诊断与改写对照](troubleshooting.md) 选择修正。暂时无法定位原因时明确是待验证假设；不要同时改模型、参考、机位和风格，让下一次结果无法比较。重试与采用遵循对应操作规则，返修保持在本次目标片段内。
