# 图像模型提示词适配

为已确定的画面设计与参考素材匹配模型提示词格式；换模型时保留已确定的画面设计。

## 先确认操作与目标模型

先区分新图生成、局部编辑已有图、从参考派生新构图与多图合成。有参考图不等于编辑（人物图+场景图制作新首帧属参考生成；修改既有首帧的袖口属编辑）。只有参考/编辑能力与实际输入满足条件时才执行。

通过「系统管理」模型查询附件定位当前图片节点的真实 `provider_id`、`model_id` 与能力（不能套用视频 `catalog_model_id`）。优先依据返回的规范 `model_id` 匹配下方系列；仅凭接口协议或展示名含 `image` 不推定系列，未知时使用通用配方：

| 图像模型 | 读取 |
|---|---|
| GPT Image | [GPT Image 写法](gpt-image-prompts.md) |
| Nano Banana / Gemini 图像 | [Nano Banana 写法](nano-banana-prompts.md) |
| Midjourney | [Midjourney 写法](midjourney-prompts.md) |
| Seedream | [Seedream 写法](seedream-prompts.md) |
| Qwen Image / 千问图像 | [Qwen Image 写法](qwen-image-prompts.md) |
| 其他模型或尚未确定模型 | 现有图片配方 |

只加载目标模型对应的那 1 份附件。参考上限、编辑模式、画幅、尺寸和质量档位全部按渠道查询结果配置，留在参数与交付说明中；不在正文写“4K”或比例参数代替配置，也不抄第三方平台字段。

## 同一画面适配与共同要求

适配模型时保留已确定的画面依据（用途、主体与状态、各参考分工、空间关系、光色材质、准确文字与保留/改动范围），并统一遵循以下底线：

- **独立按依据改写**：从共同画面依据出发重写为目标模型习惯的句式，不把 A 模型的成稿连环转译给 B 模型而积累偏差；单场景用自然段，多区域定妆版可分区，不强求 JSON 或固定栏目。
- **引用与基底真实传入**：使用应用实际双属性标签 `<ref input_id="…" label="…" />`（或按工具契约绑定的输入）指代参考或基底图，写清每张参考负责身份、服装、场景还是局部标记，不继承参考原图的摄影棚背景或无关模特；禁止省略属性的 `<ref>` 简写、复制假编号，也不要以为聊天提过上一轮图接口就会自动带着。
- **静帧只写同一时刻**：不把视频的 `Shot`/时间码和声音过程搬入静态图片提示词；多格并排或组图能力须与通道返回一致。
- **看实际图验收再返修**：已有成功提示词优先保留作基线，出现具体问题后再针对对象、区域或输入参考修改；生成后直接查图核对目标变化、非编辑区漂移、准确文字及 alpha 透明需求，不轻信正文写了“保持”就等于未变。
