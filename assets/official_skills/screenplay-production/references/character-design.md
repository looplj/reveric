# 人物选角与造型

角色设计要回答三个问题：镜头为什么停在这张脸上、观众从什么看出人物处境、同场人物靠什么区分。

## 从剧情事实到可见选择

读取人物外貌、年龄、身份、性格、时代地域与本场活动。保留已有明确设定；未确定的细节、色彩和服装作为造型提案说明，不写回原著事实。

先用一小段确定“外在第一印象 + 可见依据”，有戏剧反差时标明反差落在哪里（如端正而放松的肩颈体现从容，略抬的眉梢与集中目光体现好奇），不堆砌“高贵、绝美、灵动”等形容词。多个审美要求并存时分配到不同部位（例如亲和落在神态、庄重落在服装结构），避免各部位同时承担互相对立的要求。

| 设计层 | 需要做出的选择 | 容易失效的写法 |
|---|---|---|
| 选角与神态 | 把脸型骨相与当前表情分开：脸长宽比、颧颊下颌过渡、眉眼间距定身份；视线、眉部张力、嘴角状态定这一刻神态 | 只列发色瞳色；人人共用同一套尖下巴大眼；靠与剧情无关的疤痕强行区分 |
| 轮廓与重心 | 发型体积、肩线、腰线、衣长、裙裤量感与鞋底厚度互相平衡；发型发束与领口、肩部、饰品留出轮廓间隔 | 只写古装/西装/长裙；把高领、披发、繁复项链与厚肩饰全挤在脸周互抢 |
| 配色 | 确定颜色主次、面积比例与落点，确保角色在设定光色和背景下可辨 | 一串颜色无面积分配；人物与背景糊成一片；群像仅靠发色区分 |
| 材质与做工 | 用织物垂坠、挺度、反光、接缝、扣件与磨损位置体现生活条件和时代 | 只写“高级面料”；把自然肤质误写成沧桑，把年代感误写成脏旧 |
| 妆发与风格自洽 | 按场合、年龄与选定画风安排妆浓淡和比例；真人、二维、三维或人偶化各守自身比例和材质逻辑 | 同框混写夸张人偶比例与严格真人比例再用“禁止动漫脸”抵消；把单场伤污永久绑定身份 |

写足够少但相互协调的决定性特征，不逐毫米罗列五官，也不用质量词凑细节。修改气质或场合造型时，优先让神态、妆面与发型秩序承担变化，锁定原有脸型与骨相，不为“更冷艳/更威严”顺手换脸。

## 服装、阶层与立体延续

把社会身份、年代与工作条件转成可见剪裁、面料养护与穿着方式，而非仅写身份名词：

- **非当代或架空服饰**：写明所属时代与文化语汇，再交代领型、门襟、袖口、腰线与下摆；仅写“衬衣、外套、长裤”容易被模型按当代成衣处理。架空混搭需说明轮廓、装饰与材质各自承担什么，不把多个风格名并列了事。
- **阶层与磨损**：日间克制装束仍通过合身剪裁、整齐接缝与保养良好的面料体现条件；劳动装束按实际活动余量与摩擦部位决定旧痕，不自动涂泥。
- **同场区分**：并排对比同场主要人物的脸型轮廓、体态、服装剪影与色彩，确保至少有不依赖小饰品的识别差异。

全剧氛围与角色本地配色分开；若已定风格前后缀明显偏色并吞掉角色关键色彩，先说明影响并确认调整该图条件，不靠正面重复写“不要灰”。

### 组织配色、材质与装饰主题

- **同色系分层**：主色集中时靠物理响应拉出层次——如缎面现宽亮带、哑光织物显柔和褶谷、薄纱透出内层叠深、皮革折边出窄亮线、金属扣留小高光，而不是用强对比色破坏原配色。
- **装饰主题收束**：选定核心母题后规定主视觉位（领口/腰侧/单侧肩部等），其余部位仅用形状曲线或材质呼应，保留大面积干净衣料作留白，避免将同一图案铺满全身。

### 把正面设计延续为立体结构

多视角或转面任务先补齐正面看不见、侧面或背面必然露出的连接，不把“同一个人、同一套衣服”当作完整说明：

- **发型与不对称**：扎发/固定点位置、背面发长与发尾落点、是否遮住后领；不对称设计统一用人物自身左右标定。
- **衣物与饰件**：肩袖连接、前后衣长、门襟/拉链/系带/开衩在哪一侧、哪些装饰只在前侧出现（不把前胸装饰复制到后背）。

## 造型示范：年代架空角色

以下原创教学例用于说明“设计意图 → 可见选择 → 局部修正”如何落到正文，不作为固定角色模板；实际使用时按当前项目画风补入风格设定：

- **已知设定**：十七岁伯爵之女艾琳，金发绿眼、高挑，近代欧洲风格架空工业王国；家境优渥，性格好奇。
- **设计推导**：亲和感落在舒展的眼角、微扬的眉梢和集中目光；年代与条件落在丝毛混纺立领日间长裙、整齐前襟包布扣、克制的珍珠耳钉与自然日间肤质（不依赖皇冠或浓妆）；主色用浅青，与金发、绿眼和象牙白领口拉开面积主次。

```text
时代写实人物艾琳，十七岁女性，近代欧洲架空工业王国风格。柔和的椭圆脸，颧颊过渡自然；浅金眉、清澈碧绿杏眼，目光专注带微扬的好奇神色。蜂蜜金发半束于耳后，余发自然垂肩；肩背舒展挺直。穿浅青色丝毛混纺日间长裙，配象牙白细蕾丝立领与前襟小包布扣，自然腰线收束出整洁钟形裙摆，配浅灰青系扣短靴与小颗珍珠耳钉，妆面清淡、肤色自然。
```

**局部纠偏原则**：若已有脸型年龄合格但衣料显得廉价塌软，应锁定脸与年龄，只提高面料挺度、剪裁结构与做工精细度；若发饰、高领与项链在脸周过度拥挤，只需移去颈部冗余饰品或将发束向后收，保留已确认的面貌与衣料。

## 验收与对照

先看实际图片再下结论：先缩到接近观看尺寸检查剪影、视觉焦点与配色主次，再放大检查五官比例、材质层次与侧面/背面连接结构。

| 观察到的问题 | 优先检查与调整 |
|---|---|
| 好看但群像趋同 | 是否只改发色衣色、未建立骨相与体态比例差异；已确认脸不自动重选 |
| 气质只留在文字里 | 眼神、眉眼张力、嘴角与肩颈姿态有没有具体落点，是否堆了互相打架的风格词 |
| 精细但上下打架 | 发型体积、领型、肩部与饰件是否争夺同一轮廓，需减少脸周堆叠并分出主次 |
| 深浅色糊成一片 | 同色材料反光、叠层透视、光线方向是否能分清结构边缘，是否被风格前缀吞色 |
| 转面跑偏或串装饰 | 侧面/背面发型收束、门襟开合和左右标定是否缺失；调整后仅核对改动项并保留合格面貌 |
