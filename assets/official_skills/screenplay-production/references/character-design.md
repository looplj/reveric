# 人物选角与造型

角色设计要同时回答：镜头为什么愿意停在这张脸上，观众从什么看出其处境，同场人物靠什么区分。制片人物参考按 [图片资产与参考](image-references.md) 区分身份、服装与结构用途选择形式；设计判断不等于必须先生成一轮单幅选角图。

## 从剧情事实到可见选择

读人物外貌、年龄、身份、性格、时代地域和本场活动。保留已有明确设定；尚未确定的脸部细节、色彩和服装作为造型提案说明，不把它们写回原著事实。人物弧光和关系设计属于相邻创作技能，这里只将已有内容转成可见形象。

先用一小段定下“外在第一印象 + 内在反差 + 可见依据”。例如贵族少女可以是受宠养成的从容，遇见陌生事物时又藏不住好奇；依据是端正而放松的肩颈、略抬的眉梢与集中注视的眼睛，不是堆写“高贵、绝美、灵动”。反差来自剧情，不强加给所有角色。

| 设计层 | 需要做出的选择 | 容易失效的写法 |
|---|---|---|
| 选角 | 符合年龄的骨相与软组织、脸型和眉眼关系、少量有辨识度的特征；角色需要的亲和、威慑或机敏如何出现在眼神与姿态中 | 只列发色瞳色；每人都用同一套尖下巴、大眼睛、高鼻梁；用疤痕或纹身补辨识度却无剧情依据 |
| 轮廓 | 肩线、腰线、衣长、裙量或裤形、发型体积，缩小后仍能认出的外形 | 只说古装、西装、长裙；不分身份地堆大袖、盔甲和珠宝 |
| 配色 | 一种主色、一种辅助色及少量点缀，并指明落在什么部位；已有设定优先，不强制凑满三色 | 一串颜色没有面积关系；角色与背景全变成同一片灰褐；同场角色仅靠发色区别 |
| 材质与做工 | 面料的垂坠、挺度、反光与织纹；接缝、领口、扣件和配饰尺度如何体现生活条件 | “高级面料”没有物理特征；将自然皮肤误写成粗糙衰老，将年代感误写成脏旧 |
| 妆发与状态 | 发际与分缝、束发位置、发丝秩序，符合场合与年龄的妆面；本场的干湿、伤势和疲态 | 自动给所有女性浓妆、所有男性油头；把一次战损永久附着在身份上 |

写足够少但互相协调的特征。脸部描述选择真正决定长相的关系，不逐毫米罗列五官，也不靠“8K、杰作、超精细”替代取舍。俊美与普通都须符合人物；吸引力可以来自聪慧、坚定、幽默或经历，不把所有人修成同龄模特。

## 服装必须说清阶层、场合与时代

“贵族”“贫寒”“军人”是设计依据，不是模型一定会落实的服装指令。把社会身份变成剪裁、面料、养护和穿着方式；同一个人出席宴会、居家读书、逃亡时应有不同的服装状态。

- 贵族日间装可以克制，但仍有合身的定制结构、精细的接缝、保养良好的面料与小而考究的配饰。少戴珠宝不等于粗麻布、塌软裙形或褪色旧衣。
- 劳动者的衣着也可以干净、耐用而有性格；由工作说明磨损部位和活动余量，不自动涂满泥污。
- 古代、近代或架空作品先说明衣着语汇所属的文化与时代，再写领型、门襟、袖口、腰线和下摆。架空混搭需有设计依据，不声称它是精确历史复原。
- 花纹和装饰围绕一个可辨认的主题收束，按领口、袖口或裙摆安排疏密。细节只在对应景别展开，不让全身提示词被几十种首饰淹没。

同场主要人物并排比较面部轮廓、体态、服装剪影与色彩；至少有不依赖细小饰品的区分。不能用“贵族都穿白、反派都穿黑”的固定映射替代剧情与世界观。

## 确定造型并制作完整参考

1. **先确定视觉方向。** 核对项目已有风格、用户参考和实际生成会拼入的前后缀。真人影视、三维动画和二维插画各选一套一致语汇。皮肤微纹理、真实织物与自然光适合真人；渲染器、卡通比例等只在对应风格下使用。
2. **检查并复用已有参考。** 核对下游是人物参考还是转面，符合配方的四区板或结构图直接使用。形象待定时可以询问是否选角，不为缺少四视图而自动另做选角图。
3. **补齐任务需要的素材。** 人物参考按 [图片资产与参考](image-references.md) 的四区配方制作，作为模型参考输入；建模与转面另做几何对齐的结构图，只补本次任务缺口。
4. **核对后再扩展。** 按用途检查面貌、服装细节或结构一致性，确有镜头用途时再追加角度、表情或细节，不机械凑格。

全剧气氛与角色自身配色分开。工业背景可以灰暗，贵族的衣料仍可以光洁；悬疑片的夜戏可以低调，身份图仍需辨清眼睛、发色和衣服。风格前后缀与人物目标冲突时先说明具体影响，再调整该图的风格或测试条件；用户指定的风格需先确认调整，不静默改变全剧风格，也不靠正文反复写“不要灰”抵消互相矛盾的指令。

## 造型示例：近代架空贵族少女

以下是原创教学角色艾琳，不是任何作品的原著设定。假设已确定：十七岁、金发绿眼、高挑、欧洲近代风格的架空工业王国、伯爵之女，家境优渥且好奇。脸部细节、浅青服装与珍珠为本次提案；保持符合年龄的日间着装与自然神态。

设计意图：受宠少女的明亮亲和，与良好教养形成的端正姿态并存。柔软金发和清澈绿眼是第一记忆点，浅青衣料、象牙白领口和小珍珠构成安静的第二层；贵族感来自精细做工，不靠皇冠或晚宴珠宝。

下面保留艾琳的面貌、神态与衣料设计。制作定妆板时，将这些内容放入 [图片提示词配方](image-recipes.md) 的完整定妆示例，布局与验收按 [图片资产与参考](image-references.md) 执行：

```text
真人时代剧人物艾琳，十七岁的贵族少女，近代欧洲风格的架空工业王国。
柔和的椭圆脸，脸颊保留少女的饱满，颧骨与下颌过渡自然；浅金色细眉，清澈的碧绿杏眼，外眼角舒展，鼻梁细直、鼻尖柔和，唇形清晰而不厚重。柔顺的蜂蜜金发从额侧梳开，耳后半束，后部自然垂落，发顶蓬松但梳理精细。肩颈舒展、背部自然挺直；嘴角带一点克制的笑，眉梢轻抬，目光专注，像刚听到一件新奇的事。
浅青色丝毛混纺日间长裙的合身上身，象牙白细密蕾丝立领，袖山圆润但不过度蓬大，袖口收窄，前襟整齐排列小包布扣。合身上身在自然腰线收束，裙体由多片裁片形成整洁的钟形轮廓，裙褶从腰下有秩序地垂落，长度至脚面，裙摆只留一道细窄同色滚边；浅灰青色皮革系扣短靴。衣料表面平整，随褶面出现柔和细光；只佩小颗珍珠耳钉与细窄发带，妆面清淡，保留自然肤色与细微皮肤纹理。
金发、绿眼和浅青衣料各有清楚色相；没有皇冠或粗麻衣料。
```

如果已有合格脸但服装像农家衣着，只改面料、剪裁、装饰与衣物状态，并锁定脸与年龄；不要为“更贵气”同时换脸、换时代、换成成年晚宴装。若原有脸也不合角色，先说明不符之处并询问是否重新选角，不自动换脸。

## 看到什么才算通过

先看实际图片，再描述结论。可先缩小到接近观看尺寸，再放大面部和关键衣料：

| 检查 | 通过依据 | 不通过时先改什么 |
|---|---|---|
| 角色与阶层 | 去掉姓名仍能读出大致年龄、处境与本场身份；服装养护和做工支持设定 | 将身份标签改成剪裁与材质，不先换模型 |
| 脸与神态 | 符合年龄，脸部特征协调，眼神有明确关注点，表情与角色相符 | 修正面部设计与冲突描述；需另做选角图时先由用户选择 |
| 轮廓与色彩 | 缩小后仍能读出发型与衣服轮廓，主辅色清楚，关键颜色未被风格吞掉 | 查实际合成提示词与风格，再修轮廓和颜色分配 |
| 群像 | 同场人物不只是换发色、换衣服的同一张脸 | 对照骨相、体态和轮廓，不擅自加身体标记 |
| 完整性与可复用性 | 满足本次身份、服装或结构用途，相关素材属于同一个人，年龄和衣着状态一致 | 只补任务需要的细节或角度，不为凑板扩图 |

一次成功只验证这一角色、这一模型和这组条件。对比前后结果时记录原始与实际提交提示词、模型、画幅、参考及风格条件；若同时改变构图或去掉风格，明确这是整体方案对比，不声称已隔离出单一原因。没有真实生成时只交付待验证方案。
