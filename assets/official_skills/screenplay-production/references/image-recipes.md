# 图片提示词配方

本附件提供场景空场、空间站位、道具证据/效果、首尾帧合成与分镜拼图配方。

## 场景空场与多观察面

先建立同场不可变的空间事实（出入口、固定家具、主光源方向与色调），先出主视角空场，再由此派生不同观察方向的正反打参考，保持“房内方位固定、屏幕左右随视角正常反转”。

```text
[时间/天气与场所]空场。机位在[起始入口/方向]向[目标墙面]平视。
画面左侧是[固定设施 A]，中央为[主要桌面/通道]，右侧是[固定设施 B]，尽头为[门/窗/背景通道]。[主光源方向与冷暖]照亮对应受光面与地面通道，各材质保留各自纹理。无人，不绘制标注符号。
```

**派生另一侧机位**：明确“沿用同一参考空间，机位改为从[原方向反侧/斜侧]朝[新方向]观察；原房间尺度、门窗与灯具位置保持不变，只改变取景范围，留出本端人物站位”。多张空场并排检查门窗是否跨墙瞬移、光源开关是否改变。

## 空间站位示意图（斜俯视）

需要用图片一次交代复杂多人站位与机位关系时：

- **节点命名**：节点/片段 `title` 标明范围、场次与动作起点，不放进提示词正文。
- **核心要素**：斜上方约 45°（或顶视）观察，必要时剖开遮挡墙顶；用明显不同的纯色简化人形（或文字标识）区角色，另用相机符号标清拟用拍摄机位；标清朝向、脚部落地、通道畅通及道具处于动作前的初始状态。
- **下游继承声明**：将站位图送入正式关键帧或视频合成时，必须注明**只继承人物站位、朝向、相对距离与相机轴线**，不继承简化人形、识别色、相机图标或斜俯视角；人物造型与场景光色另取对应参考。

## 道具全貌与证据面

按用途只出需要的图，不机械制作整套状态板。若生效视觉风格已由系统配置注入，正文不重抄风格全文，只写落在道具具体部位的材质与受光表现：

| 设计层 | 需要落实到正文的选择 |
|---|---|
| 形制与比例 | 轮廓、结构接缝与连接件，以及相对人体（如掌心宽度）或同框物件的比例 |
| 材质与受光 | 主光方向及刃口、弧面、织物、金属、玻璃等各自的高光、漫反射或刻痕层次 |
| 附着/发光效果 | 若有附魔或特殊效果，交代来源位置、半透明外层、对邻近表面染色，并确保亮光与烟雾不遮断轮廓与连接件 |
| 承托环境 | 隔离背景的展示用简洁中性台面与接触压影；场内使用则沿用场内光源与支撑面 |

**证据特写示范（带准确刻字/文本）**：

```text
旧黄铜罗盘闭合后的底面近景，底面正对镜头完整入画，置于深灰中性毛毡上。保持掌心大小尺度与边缘轻微磨亮质感，后缘铰链位置可辨。
底面中央横向凹刻“N-04”，保留大写字母、连字符与两位数字，斜侧柔光清楚照出刻痕笔画而不在金属面形成刺眼高光。仅保留该处刻字，不额外添加商标或人手。
```

**效果道具核心写法（如附魔/发光器物）**：先确立实体轮廓与接口材质，再按“**发光内核 → 半透明外层/粒子范围 → 对周边金属/承托面的微弱染光 → 另一侧补光留住结构暗部边缘**”分层描述，避免整片过曝只剩一团白光。

## 首帧合成与交接首尾帧

同时需要角色、场景与道具参考并锁定视频起点或跨镜头交接时，先合成本镜正式关键帧：

1. **绑定并指明分工**：分别说明人物（脸、发型、穿搭状态）、场景（固定空间与光向）与道具各自继承哪张参考，标明人物自身左右手与接触距离。
2. **卡死时间冻结点**：动作前首帧保持“将触未触”或起始握姿，不提前露出下一个动作的结果。
3. **交接首尾帧成对设计**：
   - **交接首帧**：双人手部近景，递出者握住物件（标明状态、朝向与特定细节露出），接收者手掌张开在下方待接、明确留出未接触间隙。
   - **交接尾帧**：同一机位与光线，物件已落稳在接收者手心；原持有者已松手移开一段可见间隙；重要文本或局部状态保持不变。
   - 视频生成阶段再补写“移动 → 接触 → 交稳 → 松手”的连续受力过程，不以为两张静帧能自动跳过交接物理过程。

## 分镜拼图（审核用多格草图）

当需要先对齐多镜头先后顺序与景别反差时，可制作横向多格分镜草图：

- 明确格数与各格内容（每格只冻结一个动作瞬间，不叠画多姿势或运动残影）；
- 统一各格使用目标成片方向，沿用同一场内光源、人物外观与关键道具状态；
- 明确各格之间的景别变化（如中景对峙 → 手部特写 → 双人近景）与状态演进，供审核后再切取或重绘对应单格作正式参考。
