# 图片提示词配方

按图片用途选择下列配方；人物参考按 [图片资产与参考](image-references.md) 使用四区板，建模与转面另用结构图，其余图片按需准备。下面均为原创教学设定，使用时换成当前作品已确定的事实；示例中提到参考，不代表用户已经提供或绑定了该素材。

## 配方索引

| 需要什么 | 采用哪一节 |
|---|---|
| 人物长相平淡、服装不符身份、需要选角与定妆成稿 | 先读 [人物选角与造型](character-design.md) 的设计方法与完整示例，再使用本页的派生配方 |
| 分镜、视频或换装的人物参考 | 人物定妆四视图母版 |
| 建模、多视角生成或大幅转面 | 几何对齐的转面参考 |
| 古装、近代或架空时代人物 | 非当代人物母版 |
| 保持雨后、换装或伤势连续 | 状态变体与定点修改 |
| 同场正反打属于同一空间 | 场景空场与观察方向 |
| 用图片交代人物占位与空间关系 | 45° 斜俯视站位图 |
| 看清道具结构或剧情文字 | 道具全貌与证据面 |
| 多张参考合成动作起点 | 首帧合成与交接首尾帧 |
| 先比较镜头顺序与构图 | 分镜拼图 |

## 教学情境

假设剧本与视觉设定已确认：夜间修理铺，沈青站工作台西侧，罗越站东侧。沈青拿起桌上闭合的黄铜罗盘，翻看底面刻字“N-04”，再交到罗越伸出的右手中。沈青右袖肘部以下淋湿，其他衣物未湿。两人相对形成东西向轴线，机位保持在工作台南侧。

设定中的沈青约三十岁，窄长脸、平直眉、齐下颌黑短发，身形清瘦；穿深灰工装夹克、米白圆领内衫、黑色直筒裤、深色平底鞋。这里的年龄、外貌和服装仅属于示例，不能从“修理铺”“雨夜”推断真实人物也长这样。

## 几何对齐的转面参考

用于需要完整正、侧、背结构的任务。先核对下游要求的姿态、视角与输入格式；下例为横排三视图，改成上下分区时仍保持各格统一尺度，不采用四区板的差异放大。

```text
基于已确认的沈青参考生成横向全身三视图，从左至右为正面、严格 90° 侧面与背面。同一人物、同一套发型服装与身体比例，各视图从头顶到鞋底完整入画。
三个人形统一尺度，头顶、肩线、腰线、膝部与脚底高度对应；采用同一标准 A-pose，双臂自然微张，侧面头与身体方向一致，背面不回头。保持头身比、肩宽、四肢长度、服装轮廓与配饰位置，不将前侧装饰复制到后背。
平视、近正交的结构展示，避免广角透视和各视图缩放差异；中性灰背景、清晰均匀的光线，无文字、无动态姿势。
```

检查实际图的结构对齐，不把提示词里的“正交”当作已经获得精确建模数据，也不以多视图齐全承诺环绕视频不会变形。

## 人物定妆四视图母版

布局、取景与验收按 [图片资产与参考](image-references.md) 的竖版四区配方执行。下例展示完整成稿；沈青的灰色工装和克制表情来自这一角色，使用时替换为本次人物与造型，保留作品已确定的画风。

```text
沈青的竖版定妆四视图，规整四宫格、两列等宽、细线分隔。上方 1/3 左正面、右严格 90° 侧面头肩特写；下方 2/3 左放大正面服装展示、右背面全身。四个视图是同一个约三十岁的沈青：窄长脸，平直眉，齐下颌黑色短发，身形清瘦、肩线平直。穿深灰棉质工装夹克、米白圆领内衫、黑色直筒裤和深色平底鞋；夹克拉链停在胸口，袖口自然放下，衣物完整且干燥。
上方头肩紧凑构图，完整保留发型，清楚展示五官、骨骼轮廓和神态。左下从肩颈下方至鞋底，头部完全出画，完整保留肩膀、双手、服装和鞋履，人物尽可能占满分区，明显比右下更大；右下从头顶到鞋底完整入镜，头与身体都背向镜头、不回头。下方两格均为标准 A-pose，双臂自然微张、双手空置；发型、身体比例、服装结构和配色一致，后背不复制前胸拉链，未展示部分合理延续。
中性灰无缝摄影棚背景、柔和三点式布光、曝光一致。真实毛孔、细微绒毛、自然发丝、皮肤纹理与布料褶皱；无美颜磨皮、塑料皮肤或 CG 感。没有额外饰品、疤痕、手持物、其他角色、文字、标签、场景布景或动态姿势。
```

已有图缺少背面、需要补齐组合图时，明确身体和头都背向镜头，不能只写“背面”却要求展示脸：

```text
绘制已提供人物母版中沈青的全身背面，身体和头部都背向镜头，面部不回转。看到黑色短发后部、夹克后背、裤装后侧和鞋跟。标准 A-pose，双臂自然微张，双手空置。
保留母版的身高比例、发长、肩宽、夹克长度、裤脚与鞋型，沿用背景和识别用光。夹克后背没有新图案，不把前胸拉链复制到后背。
```

优先从确认母版派生，必要时补确认过的面部参考，不将未经检查的派生图连续作为下一张的身份依据。若原图本身看不清脸，先解决这个缺口，不声称“引用同一图”就保证同脸。

## 非当代人物母版

模型对“衬衣”“外套”“长裤”的默认理解是当代成衣，画风选择也不会自动改变服装年代。人物属于古代、近代或架空时代时，在人物正文里写出年代与地域，把每件衣物写到形制，再排除最容易混入的当代特征。

另设一个原创示例：十九世纪末一座蒸汽工业港城，贺维是航运公司的年轻抄写员，二十三岁，收入微薄但注重体面。原文只写了黑发、灰眼和瘦高身形；衣着按年代、阶层与职业推断，交付说明中标为待确认。下面只展示人物与服装描述；四区布局和摄影条件沿用上面的完整示例，其他用途按实际取景组合：

```text
十九世纪末欧洲风格工业港城的年轻抄写员贺维，二十三岁男性。窄长脸，颧骨略高，眉形平直，灰色眼睛，鼻梁细直，薄唇，肤色偏白而缺少日晒；黑色短发向一侧梳平，发尾修到耳上。身形瘦高，肩窄，站姿端正但略含胸。
穿白色棉质衬衫，配可拆卸的低翻硬领与深色窄领结，袖口扣合；外罩深灰羊毛单排扣马甲，最上一颗扣子解开，胸前垂一条细怀表链；深色羊毛高腰直筒裤由背带吊起，裤线笔直，裤脚落在鞋面；黑色系带皮靴，鞋头微圆，有日常磨痕。衣料是哑光羊毛与棉布，袖肘和马甲下摆有轻微旧痕，整体干净但不新。
不出现当代修身剪裁、敞开的领口、卷起的袖子、拉链、运动鞋、腕表或现代发型；没有其他角色、手持物、文字、标签、场景布景或动态姿势。
```

四区板出现当代特征时，先定位缺了哪一项形制描述，修正各视图，不在派生图里逐张纠正。

## 状态变体与定点修改

交付说明记录基于哪张图、状态从哪场开始持续到哪里。下例针对已选用的四区板。图片正文只表达变化与保持项：

```text
以已提供的沈青干衣母版制作本场雨后状态图，保持同一人物与相同构图。只改变人物自身右袖肘部以下：深灰棉布浸湿后颜色加深，袖口贴近手腕，湿区与干布之间有自然的不规则边缘。
脸型、发长、体型、夹克剪裁、领口、左袖、裤装和鞋保持母版状态，背景与光向不变。保留上方正面与 90° 侧面头肩、下方放大无头正面服装与背面全身的竖版四宫格布局，各视图可见的右袖部位同步体现浸湿状态。衣物没有新破洞、血迹或伤口，不混排干衣与湿衣两套造型。
```

不要因“雨后”自动添加湿发、泥鞋或全身滴水。换装也按同样结构，明确整套新衣的关系，同时保护面部和体态；不要把换衣写成重新设计一个人物。

假设实际反馈是“交接首帧的罗盘大得像餐盘，挡住了手”，定点修改可以写：

```text
只缩小画面中央的黄铜罗盘，使直径接近罗越张开的掌心宽度，厚度比例沿用原道具参考。物件仍处在原交接位置，让下方尚未接触罗盘的罗越掌心，以及沈青握住盒体的手指清楚可见。保持沈青手指与盒体接触，保留罗越掌心与罗盘之间的间隙。
保留两人身份、手臂进入画面的方向、沈青右袖湿区、罗盘闭合状态及底面“N-04”、机位、台面和原有冷暖光。不要放大人物手掌来迁就旧尺寸，不增加物件。
```

改后检查尺度、刻字及起点手位：沈青仍握持罗盘，罗越尚未接触；不能把首帧提前改成已经接住，也不能缩小后让物件脱离沈青的手。

## 场景空场与观察方向

共同空间事实：北墙中央窄窗，南墙中央入口，东墙工具架，中央工作台。台灯固定在工作台北沿靠东，北窗冷光与台灯暖光在本场同时存在。先建立可辨认的布局，再派生本场需要的观察面。

```text
夜间修理铺空场。机位位于南侧入口内朝北看，中央工作台与北墙窄窗形成纵深，东墙工具架在画面右侧。工作台东西两端与南侧通道留有站立和通行空间，入口与工作台之间没有大型家具。
北窗透入微弱冷色环境光，工作台北沿靠东的暖色台灯照亮桌面。木台面有轻微使用磨痕，工具架结构清楚。画面无人，不放入本场罗盘，不绘制方位字样或箭头。
```

正反打参考不要求屏幕里的窗和亮区永远在同一侧，应维持它们的场内位置：

| 观察面 | 可直接使用的派生描述 |
|---|---|
| 拍工作台西端 | 同一修理铺空场，机位在工作台东南侧朝西端观察，保留西端人物站位与其后的空间。沿用房间尺度、桌子、门窗和固定陈设，不把东墙工具架搬到西墙。台灯仍在工作台北沿靠东，光源可在画外，桌面亮区与阴影由原有窗和台灯形成。 |
| 拍工作台东端 | 同一修理铺空场，机位在工作台西南侧朝东端观察，东墙工具架位于该端后方。房间尺度、窗户、工作台和灯具位置保持；不复制窗户，不改变灯具开关状态。留出东端人物站位。 |

多图并排检查能否属于同一房间、同一时刻。人物入场后，西端人物朝东，东端人物朝西；换机位会改变背景可见范围，不应改变两人的场内关系。

## 45° 斜俯视站位图

占位图的选择、制作与验收先读 [分镜指南](storyboard.md)。下面给出图片方式的具体写法；场景结构沿用已确认的共用参考。

生成前给图片节点起明确标题，例如“修理铺·罗盘交接｜占位·拿起前”；标题放在片段 `title`，不加入图像正文。保存本段对应的节点和结果 ID，修订本段时直接定位；标题负责检索和区分用途，不能代替生成后的结果检查。

从斜上方约 45° 观察，让地面、人物脚下位置、朝向、主要家具、出入口与通道同时可见。人物可用容易区分的简化人形，图外说明每个人形对应哪个角色；这些识别色不代表角色的真实衣着。室内可用剖开屋顶或遮挡墙面的展示方式露出布局，但保持原有墙体位置、门窗与房间尺度。需要标拟用机位时用与人物不同的相机符号，说明其位置与拍摄方向，不把示意图的观察点当成实际拍摄机位。

下例假设已提供并核对修理铺场景图，要表达沈青拿起罗盘之前的站位。人物对应：蓝色人形为沈青，橙色人形为罗越；颜色只作示意标识。

```text
依据已提供的修理铺场景参考，绘制一张从房间南侧斜上方约 45° 向北观察的站位示意图。以简洁三维空间示意表现，露出地面和完整工作台；屋顶与遮挡视线的近侧墙面采用剖开展示，保留房间尺度及墙、门、窗的原位置。北墙中央窄窗、南侧入口、东墙工具架、中央工作台和桌子北沿靠东的台灯都沿用场景参考。
工作台西端放一个蓝色简化人形，代表沈青，身体朝东、头朝桌上罗盘；工作台东端放一个橙色简化人形，代表罗越，身体与头朝西面对沈青。两个人形双脚落地，身高比例与桌面尺度协调，各自靠近工作台端部，手能触及桌面，不穿过家具。沈青的右手停在罗盘旁但尚未接触，罗越双手停在自己一侧桌沿。闭合罗盘放在桌上靠沈青的一端。南侧入口到工作台的通道保持畅通。
在工作台南侧留出一个与人形明显不同的小型相机符号，朝向两人和桌面，表示拟用拍摄机位；它不代表这张示意图的俯视观察点。清楚呈现人物朝向、桌子两端的相对距离和主要物件位置。画面只表现拿起罗盘前这一时刻，每个角色只出现一次，不画连续动作残影，不增加角色、家具或装饰性细节。
```

实际查看生成图，核对蓝／橙人形与角色对应、东西两端未交换、头与身体朝向正确、脚落地、手可触及物件、通道未被占用，以及相机位于人物轴线的预定一侧。人物被遮挡或布局看不清时调整示意图的观察点或剖开方式，不为露出人物擅自搬动房间结构。

后续合成首帧或生成视频时，按模型支持的输入方式绑定实际图片，并说明：此图只提供人物站位、朝向、距离和空间关系；人物外貌与服装来自人物参考，场景材质与灯光来自场景参考；最终景别和机位按本镜要求，不继承简化人形、识别色、相机符号、剖开墙面或 45° 俯视视角。需要首帧时据此另作本镜的正式构图，不直接把站位示意图当首帧。

## 道具全貌与证据面

一张图不必看清互相背对的两个面。全貌负责形制与尺度，细节图负责本镜要读到的信息。

```text
一只闭合黄铜罗盘的全貌参考。圆形盒体，直径接近成年人掌心宽度，厚度明显小于直径，盒盖与盒身接缝清楚，铰链位于后缘。黄铜表面有轻微氧化和接触磨亮区域，整体完整。
四分之三角度展示盒盖、侧壁与后缘铰链，单个物件置于中性浅灰台面。柔光让金属轮廓与接缝可辨，无人、无手、不复制物件。此角度不展示底面刻字，不把刻字移到盒盖。
```

```text
同一只闭合黄铜罗盘的底面近景，底面朝镜头并完整入画。保持参考的直径、厚度、材质和磨损，铰链连接位置不变。
底面中央横向刻着“N-04”，保留大写字母、连字符和两位数字。斜侧柔光使凹刻笔画可辨，不以强反光覆盖文字。只有这一处刻字，不添加商标、其他编号、说明或手部，不打开罗盘。
```

若需后期加准确文字，先保留清楚、无遮挡的承载面，将文字内容和合成任务写在交付说明中。不能让人物在最终成片里“读懂”尚未补上的证据；验收需看实际文字，不只检索 prompt。

## 首帧合成与交接首尾帧

下例假设人物、场景、道具的对应参考已实际提供并检查。正式提交须绑定真实输入，语义名称不能代替引用标签。

```text
夜间修理铺中景，机位在工作台南侧，保留参考空场的房间与灯具布局。沈青位于西端、画面左侧，身体朝向东端的罗越，视线落在桌上罗盘。右袖肘部以下呈确认过的湿深状态，右手停在罗盘旁但尚未接触，左手垂下。罗越位于东端、画面右侧，身体朝沈青，双手停在自己一侧桌沿。
闭合的掌心大小黄铜罗盘位于桌上，盖面朝上，底面刻字此时不可见。两人的脸和衣服分别来自对应人物参考，不互换；罗盘来自道具参考。北窗冷光与台灯暖光保留。画面冻结拿起之前的瞬间，不提前翻出底面或完成交接。
```

“拿起翻看”完成后的交接，是另一个起点。不能继续用上面的未接触首帧：

## 分镜拼图

仅需比较顺序或构图时，可先制作审核用拼图。每格冻结一个时刻，格间的动作由视频描述承担。例如本场用三格检查拿起、读字、交接，不表示模型必须按三格一次生成：

```text
制作三格横向排列的分镜草图，各格自身采用已确定的成片画幅；保持同一修理铺、人物造型、黄铜罗盘与光线。
左格：工作台南侧中景，沈青左、罗越右，罗盘闭合平放桌上，沈青右手尚未接触。
中格：罗盘底面与沈青右手近景，罗盘已经翻至底面朝镜头，“N-04”可读；罗盘仍由沈青持有。
右格：双手近景，罗盘落在罗越右手掌心，沈青已松手，湿袖保持。
各格表现单一瞬间，不在格内叠画运动路径或多个姿势，不添加对白气泡、时间码和说明文字。
```

检查中格有没有把字写到盖面、右格有没有提前开盖或复制物件。需要首帧时取相应干净单格并核对画幅；整张拼图不直接作为开场画面。
