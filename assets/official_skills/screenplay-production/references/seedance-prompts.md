# Seedance 提示词

适用于 Seedance 2.0 与 2.5 系列提示词写作，本附件只规定结构、时间与标记。实际支持的输入模式、参考素材类型（图／视频／音频）与数量上限一律以运行时模型查询结果为准，按返回的 `catalog_model_id` 选用 2.0 或 2.5 写法。

## 共同结构

正文用中文，台词保留原语言与原文：

1. **素材指代**（有绑定参考时）：写清各输入用途并插入规范 `<ref input_id="…" label="…" />`（如 `<ref input_id="…" label="林岚" />是林岚的身份参考，<ref input_id="…" label="客厅" />是公寓客厅空间参考`），人名在正文中与标签关联。
2. **可选本段共用锚点**（仅多镜且存在参考/系统风格未覆盖的跨镜不变量时加 1 句；单镜头或首尾帧直出省略，绝不剧透结尾变化）。
3. **分镜情节**：按 2.0 或 2.5 的写法逐镜交代切换/运镜、动作与表情、空间变化和声音，一镜保留一个主要运动意图。
4. **声音与末尾补充**：仅在系统风格或共用文本未涵盖时补一句无字幕／无水印要求。

## Seedance 2.0：按镜头顺序，不写秒数

2.0 只响应镜头序号，不写秒数或时间区间；需要停顿写成动作行为（「停在桌沿片刻」）。

```text
镜头1：中景固定镜头。……
镜头2：硬切至周明近景。……
镜头3：切至桌沿钥匙特写，微俯拍。……
```

多参考模式下在运行时上限内筛选，每段以 4–5 个必要素材为宜，最关键的角色／空间放前面；人物参考在名额紧张时可使用四区角色参考板整板，或直接使用已确认单人正视图（需说明同角色多视图归属一人，防止被拆成两人）。

## Seedance 2.5：整数秒时间戳

2.5 响应连续整数秒区间（首尾相接且末镜终点等于生成总时长），不靠时间戳控制微动作频次：

```text
0-4秒：中景固定镜头。……
4-6秒：硬切至周明近景。……
6-8秒：切至桌沿钥匙特写，微俯拍。……
```

## 台词与声音

- **2.0 对白**用 `{}`：`周明压低声音、放慢语速说{你真的要走？}`；画外音写「以画外音说」；小语种标注语种，如 `用日语说道{こんにちは}`。
- **2.5 对白**用 `角色台词（情绪）："原话"`（如 `周明台词（迟疑）："你真的要走？"`；外语标注于括号中，如 `角色台词（日语，迟疑）："……"`），台词后不复述原话或再追加神态，避免引发字幕。
- 音效用 `<>`（`<钥匙擦过木桌的轻响>`），配乐用 `（）`（`（低沉大提琴长音）`）。无需配乐时写明一次“只保留环境音与动作声，无背景音乐”即可。多音字或生僻字容易误读时，征得用户同意后再改同音常用字。

## 首尾帧与视频参考

- 原生首帧／首尾帧模式下，两端锁定画幅（`frames_require_adaptive_ratio` 时须使用 `adaptive`）与起止画面，正文只写中间过程，不重述图中外观；在全参考模式下，仅当未设帧 role 而以 `reference_image` 提交关键帧时，才须在正文写明 `<ref input_id="…" label="…" />作为首帧`（`inputs` 绑定遵循「工具技能」）。
- 当运行时支持视频参考时，参考视频通过 `reference` 输入传递（应用无独立延长端点）：说明 `<ref input_id="…" label="…" />` 承接前面动作还是作为动作/运镜参考，并写明接下来发生的变化与保留项。
