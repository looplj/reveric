# 人物定妆、转面与状态变体

用于编写人物定妆四视图、几何对齐转面参考、非当代母版与状态变体提示词。

下例以教学角色“沈青”（三十岁左右，窄长脸、平直眉、齐下颌黑短发、清瘦，穿深灰棉质工装夹克与米白内衫）及“贺维”演示结构写法；实际使用时替换为当前作品已确认的人物、造型与生效画风（若画风已由系统配置注入，正文不重复抄写）。

## 人物定妆四视图

四区板把面部特写与全身穿搭装入同一张参考图，是兼顾脸部像素与服装结构的高效板式。标准人形推荐**规整四宫格、细线分隔，上方两格约占 1/3、下方两格约占 2/3**：

- **左上 / 右上**：正面与严格 90° 侧面头肩特写，紧凑构图保留完整发型与五官轮廓。
- **左下**：正面穿搭展示，自然 A-pose。顶边从领口上缘裁切，头部和下巴完全在画框外，画面下方保留鞋底。大裙摆、长袍、拖尾或非人异形可按造型调整格比例与取景，完整展示关键结构。
- **右下**：完整背面全身展示，头与身体均背向镜头、不回头，保持与正面一致的身高比例，仅延续合理背面结构，不把前胸装饰/开襟复制到后背。

```text
沈青的竖版定妆四视图，规整四宫格、细线分隔，中性灰均匀背景与柔和识别用光。人物三十岁左右，窄长脸、平直眉、齐下颌黑短发、清瘦；穿深灰棉质工装夹克、米白圆领内衫、黑色直筒裤与深色平底鞋，夹克拉链停在胸口，衣物完整干燥。
上方约占 1/3：左上正面头肩特写，右上严格 90° 侧面头肩特写，完整保留五官骨相、发缝与发型边界。
下方约占 2/3：左下为正面 A-pose，顶边从领口上缘裁切，头部和下巴完全在画框外，从领口到鞋底完整展示拉链、衣袋与鞋型；右下为从头顶至鞋底的背面全身 A-pose，头身均背向镜头，后背保留纯净衣面与发尾收束，不复制前胸拉链与口袋。四格为同一人物、同一画风与色彩。
```

**缺失视角补全**：已有正面/三视图但缺背面时，传原图明确“身体和头均背向镜头、面部不回转，延续发尾、衣长、裤型与光色，不把前侧拉链/徽章复制到背面”。若原图面部像素本身模糊，应重做或补充清晰面部图，不连续从糊图派生。

## 几何对齐转面参考（三视图）

用于建模或大幅环绕镜头，要求各视图**同一尺度与同一基准高度**，避免四区板的差异放大：

```text
基于已提供的人物参考生成横向全身三视图，从左至右依次为正面、严格 90° 侧面与背面。各视图保持统一尺度，头顶、肩线、腰线、膝部与脚底处于同一水平高度线；采用近正交平视，减少广角透视畸变。统一标准 A-pose，双臂微张，侧面头身朝向一致，背面不回头；完整保留头身比、服装与配饰左右位置，后背不复制前侧装饰。中性灰背景，均匀识别用光。
```

生成后直接看图核对高度与左右一致性，不把提示词写了“正交”当成精度保证。

## 非当代人物母版要点

写古代、近代或架空人物时，必须在人物正文中点明**时代语汇**，并把领型、门襟、袖口、腰身与鞋履写实（仅写“衬衫/外套/裤子”模型会回落到当代成衣）；只在最容易跑偏之处补充具体排除（如避免拉链、运动鞋、当代修身剪裁）。

核心写法结构（替换成具体时代）：

```text
[时代与文化语汇]，[性别年龄与骨相神态]，[发型梳理方式]。
[内层领型与扣法] + [外层剪裁、袖口、门襟与腰部固定] + [下装裤型/裙摆高度与鞋履细节]；衣料交代[纹理、光泽与微旧痕迹]。
保持时代形制准确，不出现拉链、现代运动鞋、现代手表或当代修身翻领等时代冲突元素。
```

## 状态变体与定点改图

从确认母版派生临时状态（如局部淋湿、战损、换装）或修正道具/构图比例时，把**变化范围、保持项、不变布局**分开写清，只改目标，不趁机发散其他特征（如“雨后局部湿袖”不自动改成全身湿透或乱发）：

```text
基于已提供的人物母版生成状态变体，保持人物身份、发型、体态、主服装结构、四宫格布局与背景用光完全不变。
本次仅修改人物自身右袖肘部以下：布料呈雨水浸湿后的深色微重质感，略贴手臂，袖口边缘有自然湿痕边界。其余部位保持干燥完整，不混排干衣与湿衣对照，不新增伤污。
```

道具/结构定点纠偏（如修正过大的手持物或被遮手部）采用同样句式：**说明修改后的相对尺度参照物（如“直径接近角色张开的掌心宽度”）+ 必须露出的接触部位 + 显式保持的未变元素（人物手位、刻字、光向、场景）**。
