# 分镜指南

负责整体镜头设计：如何拆镜、安排景别与切点、组织空间和动作，以及保持前后连续。具体运镜表达和镜头提示词组合见 [镜头任务配方](shot-recipes.md)。

## 镜头职责与切点

先回答这一镜让观众看见什么变化，再选景别与运镜。建立空间、揭示信息、展示动作、捕捉反应都可以成为镜头职责；切镜应带来信息、视角、情绪或节奏的变化，不为凑镜头数重复同一内容。

- 全景或中远景交代人物关系、出入口和行动路线；中景承载互动；近景突出反应；特写承载需要看清的细节。景别由信息需要决定，不套固定比例。
- 对白切点可以落在说话者、听者反应或承载潜台词的动作上，不机械地一句一切。先估算按指定语速读完原话所需时间，再安排不能重叠的动作、停顿和反应。台词太长时拆段，用户要求改台词时再调整文本，不靠“快速说完”塞进短窗口。
- 人物动作与运镜分别写清。一镜优先安排一个主要运动意图，确定它承载的注意变化和起止构图。需要稳定空间、精细动作或细微表演时可以固定机位，不强加环绕、甩镜或变焦。
- 竖屏先保证主体、互动对象和关键道具能同时读清；多人横排容纳不下时用纵深、前后景或反应切镜组织，不只把横屏构图裁窄。

## 从叙事目的选镜头

| 观众此刻要获得什么 | 可选镜头组织 | 写作时落实的条件 |
|---|---|---|
| 明白人物与出口的关系 | 建立镜头后进入人物中近景 | 入口、人物轴线与行动路线能辨认；不必每次都从全景开始 |
| 听懂一句话怎样改变关系 | 说话人近景切听者反应 | 用目光、呼吸或动作承载变化；画外对白不把说话人重新拉入画面 |
| 看清谁拿走了关键物件 | 中景交代双方，再用手部插入镜头 | 接近、接触、共同持有、释放及归属顺序清楚；不可让遮挡代替必需动作 |
| 发现先前被遮住的信息 | 主体位移或单一运镜逐步露出 | 写清遮挡物、被遮对象、露出的时刻和终点；不让秘密在首帧已经可见 |
| 感到人物被困或孤立 | 拉远、保留前景遮挡或扩大留白 | 被揭示的空间确实属于本场；不是用任意广角词替代空间关系 |
| 连接独立生成的相邻片段 | 反应、相关物件或景别变化的切点 | 事件继续而非重演；同姿势精确匹配是另一种要求，需要实际尾帧依据 |

运镜选择服从镜头目的：人物奔跑也可以留在固定画面中，情绪加重也可以靠表演与构图完成。固定与移动同样是主动选择，不设每场必须移动的配额。设计确定后，按 [镜头任务配方](shot-recipes.md) 的运镜对照表与示例组织具体提示词。

## 占位图先解决空间，再写表演

当互动位置、越轴、遮挡或运动路线仅靠文字难以判断时，可用占位图明确空间关系。占位图可以使用导演台静帧／预演，也可以使用 45° 斜俯视站位图，不要求两种都做。占位图对应当前分镜和具体动作起点，按本段需要制作，不先搜索、读取旧占位图来判断能否跨段复用。只验证对白措辞时无需新建布景或生成占位图。

| 方式 | 适用任务 | 制作方法 |
|---|---|---|
| 导演台 | 调整人物与机位、检查多个角度或连续走位 | 为当前分镜配置人物、关键物件与机位，按需导出静帧或预演 |
| 45° 斜俯视站位图 | 用一张图交代静态布局、站位、朝向与相对距离 | 根据已确认场景画斜上方约 45° 的空间示意，人物可用可区分的简化人形；完整提示词见 [图片提示词配方](image-recipes.md) |

两种方式都要核对人物身份对应、朝向与视线、关键物件归属、出入口与通道、相对距离、遮挡和拟用机位。区分场内方位与图上的左右，不因换观察角度移动门窗或交换人物。占位图的 45° 俯视角只是展示布局的观察角度，不自动成为最终镜头机位。

用“本次范围、分镜、占位和动作起点”命名图片节点或导演文档，记录本段对应的真实 ID。修订、重试本段时继续使用本段已建立的节点或文档，不重复创建。需要看图时直接检查本次结果。

静态图表示指定动作时刻，不能证明走位、接触和释放的全过程；确需检查过程时，再用导演台预演或分别画必要阶段，不在同一静帧里重复摆出同一人的多个位置而不说明。占位图不替代本镜所需的人物身份、服装或结构参考、场景美术参考或最终首帧；向生成模型说明只继承空间关系，不照搬简化人形、识别色、标记或俯视角。

### 使用导演台

1. 读取本次剧情依据和目标导演文档，明确每个节拍的起点、接触、完成和停留时间。同一次调度共享一条时间轴；超过导演文档时长上限时说明限制，按动作阶段拆段，不删掉剧情来凑时长。
2. 先安排人物、出入口和关键物件，检查谁面对谁、距离与通路。道具优先从内置 GLB 目录选择，摆放前核对底面或握持点原点；坐面、床面和桌面按支撑高度对齐，不用模型总高度代替。具体规格与摆放规则见「工具技能」的导演文档附件。姿态预设提供静态姿势；完整姿态键连同高度表达下蹲、抬腿、倾倒和停留。路径只做走位，迈步、踢击等过程需要补姿态键，不声称具有自动步态或动作捕捉效果。
3. 以景别职责安排机位，在动作开始、接触、完成处检查构图；正反打保持人物轴线。注视可绑定人物或骨骼，切镜单独安排；移动机位不会自动切换输出镜头。保留倒地、反应和关键道具状态的可读停顿。
4. 先用 sample 检查关键时刻，再运行完整 validate，随后检查实际 PNG、切点前后帧和 MP4。看清头脚是否无意裁切、支撑是否悬空或穿地、人物是否漂移，以及实际切镜和节拍是否一致；数值通过不等于画面合格，第零帧也不能证明全过程。
5. 交付前核对保存重开和实际输出。粗略人物模型只表达空间、姿态与镜头意图，不把白模颜色或僵硬关节当成最终造型与表演；手工编排不冒充模型自动完成。

向视频模型说明哪些内容来自预演（机位、路线、入画时机），哪些来自人物或场景参考（身份、服装、材质）；没有人物参考时用已确认外观，不用白模颜色编造衣着。预演缺少关键动作时先修预演或调整参考职责，不同时要求严格照做和擅自新增另一套动作。字段、帧率、姿态与路径、切镜、预览与导出都由「工具技能」的导演文档附件维护。

## 起点、动作与终点

用“起点 → 可见过程 → 终点”设计动作。交接、换手、取放物件时写清哪只手、与谁接触、物件最后在哪里；不能让物件在两段之间凭空换人。首帧只描述动作发生前可见的状态，不提前放入终点才出现的结果。

把抽象心理转成可拍的载体，例如“意识到被背叛”可表现为视线停在署名处、手指收紧、再抬头看向对方；具体表现必须符合原文与人物，不能擅自增加剧情证据。复杂手部操作、多人精确接触、连续变形和复杂运镜同时出现时，优先拆成同一次生成内的 Shot、改变取景或使用插入镜头，保留戏剧结果，不用删戏掩盖生成难度。确需跨生成任务拆分时，先按 [制片流程](production.md) 选择动作阶段终点和连续性方案。

终点必须能在本镜取景中看见。固定人脸近景不能直接以“桌下钥匙落地”为结束画面，需要明确俯摇或另切物件镜头；仅有落地声时它属于画外声音。“保持位置”也不等于所有人冻结，非主要动作的人可自然呼吸、倾听或延续已有活动，不为保持连续性写成静止人偶。

## 连续性

先区分同一次生成内的切镜与两个独立生成任务。跨任务先按 [制片流程](production.md) 的“先设计段间接缝”选择衔接方式与输入依据，再安排并发；以下检查用于落实镜头中的连续性。

- 相邻镜头核对人物位置、朝向、视线、屏幕运动方向、衣着、持物、伤痕、光线与道具状态。反打保持空间关系；需要越轴或换方向时，用可见的机位运动或重新交代空间的镜头过渡。
- 区分动作连续、正常切镜和时间／地点跳转。下一段接着上一段已经完成的动作，不把开门、递物等事件重演一次；时间和地点变化可以明确切换，不必强行无缝续接。
- 计划中的结束状态不是实际生成结果。用户要求接着已生成视频续拍时，以用户提供并可核对的实际尾部状态为依据；只有文字计划时可准备后续草稿，但不能声称已经匹配真实画面。
- 根据实际采用结果核对跨段衔接，引用操作按「工具技能」执行。Agent 无法观察采用视频时，不根据标题猜其构图或动作；可读取实际文件并提取尾帧，仍无法确认时请用户说明。
