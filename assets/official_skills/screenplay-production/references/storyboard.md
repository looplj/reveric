# 分镜指南

负责整体镜头设计：拆镜、景别与切点选择、空间和动作编排及前后连续性。具体运镜与组合配方见 [镜头任务配方](shot-recipes.md)。

## 场内状态与逐镜可见范围

先依据剧情、已确认设计与实际参考定下场内人物、关键物件与固定环境的位置、朝向和持物。某人即使不在画面内或没有台词，只要未明确离场就保留其场内定位供后镜承接。换机位时继承上一镜末态并重算画面左右与遮挡，同场新入画主体通过背景、视线或动作与前镜建立空间关系。

## 镜头职责与切点

先问“这一镜要让观众看到什么变化”，再选景别与运镜；切镜应带来信息、视角、情绪或节奏推进，不为凑数重复。

- 全景/中远景立关系与行动路线，中景载互动，近景抓反应，特写显细节。
- 对白切点落在说话人、听者反应或潜台词动作上，不机械一句一切；预留口型时间，台词过长则拆镜，不靠“快速念完”塞进短窗口。
- 动作与运镜分写，一镜优先服务一个核心运动意图；需稳定阅读空间或精细手部动作时使用固定机位，不强加环绕或甩镜。
- 竖屏构图先保证交互双方与道具同时可读，人多排不下时用纵深或切镜解决，不硬裁横屏。

| 观众需要获得的信息 | 可选镜头组织 | 落地要点 |
|---|---|---|
| 明白人物与出口关系 | 建立镜头切中近景 | 入口、轴线与移动路线可辨（不必每场都先出大远景） |
| 听懂话语如何改变关系 | 说话人近景切听者反应 | 用目光或动作反应承接，画外音不把说话人硬拉入画 |
| 看清谁拿走了关键物件 | 中景交代双方再切手部特写 | 接近、接触、共持、释放与归属顺序清楚，不用遮挡掩盖交接 |
| 发现此前被遮住的信息 | 主体让位或单一运镜逐步露出 | 写清遮挡物、被遮物、露出时刻与终点，不在首帧剧透 |
| 感受被困或孤立 | 拉远、保留前景压迫或留白 | 被揭示空间符合本场设定，不拿广角词代替真实关系 |
| 衔接独立生成的相邻片 | 反应、物件或变景别切点 | 事件继续而不重演；仅在确有剧情需要时才采用同姿势无缝匹配 |

## 占位图先解决空间，再写表演

文字不足以厘清多人站位、越轴、遮挡或走位路线时，按本镜需要选做一种占位图（只验对白无需制作）：

| 方式 | 适用情况 | 要点与边界 |
|---|---|---|
| 导演台预演 | 多机位角度调试、连续走位与节拍检查 | 读取本次剧情依据和目标导演文档；具体字段与预览操作见「工具技能」导演文档附件；粗模只定空间路线、姿态与机位，不充当成片造型 |
| 斜俯视或顶视站位图 | 一图确定静态布局、朝向、通道与距离 | 用可区分简化人形示意空间，提示词配方见 [图片提示词配方](image-recipes.md) |

两种方式均需核对身份对应、朝向视线、物件归属、出入口、距离与拟用机位，并按“范围＋分镜＋起点”命名复用，不重复新建。向视频模型引用时，明确声明**仅继承空间关系／机位节奏，不继承简化人形、白模颜色、标记或占位俯视角**。

## 起点、动作与终点

按“切入时态 → 镜内变化（触发／过程／终点）→ 摄影机观看变化”组织每镜正文。交接、换手或取放须写清左右手、接触面与最终归属；首帧只写动前可见态，不预先包含终点结果。

- **终点必须在当前取景中可见**：若固定人脸近景无法看见脚边或桌下动作，应明确补俯摇运镜或另切特写镜头，否则只能作画外声音处理。
- **抽象心理外化**：转成视线停留、停顿、指节发力或呼吸变化等可拍表现，不擅自杜撰原剧本没有的物证；高难多任务动作优先拆成同段内多个 Shot 或插入镜头。
- **连续运动与揭示**：先定“人物何时察觉 → 观众何时看见 → 相机为何动”，长镜头仅在连续过程本身值得观看时启用；范例见 [动作对抗案例](examples/shot-combat.md) 与 [连续运动与揭示案例](examples/shot-continuous-reveal.md)。

### 动作与场面差异化（仅动作／奇观场景按需使用）

设计角色交锋应依据人物性格、体格与兵器，写清**常用距离、发力习惯、受压代价与破招利用**（如重盾正面推进但转身偏慢，轻剑靠侧移诱导转身），不让双方机械复读同一套连招或临时空降未铺垫大招。升级节奏围绕**空间拓展、战术被迫改变、尺度对比或声画强弱收放**展开，先交代旧办法为何失灵。

特效按“来源 → 路径 → 接触 → 环境响应 → 消散残留”落笔，实体兵器材质与附着光效分开写，且不让光效遮断角色轮廓或接触动作；完整案例见 [破盾开路](examples/shot-stylized-action.md)。安静文戏回归表演与信息组织，不为套用递进而硬加打斗或光效。

## 连续性检查

相邻镜头核对站位、朝向、视线、屏内运动方向、衣着、持物、伤痕与光线；正反打维持轴线，换向或越轴靠可见运镜或过场交代，不做隐形跳变。下段承接上段已完成动作时不重演已发生事件；跨生成衔接策略与参考绑定复查按「工具技能」及制片规范执行，不以文字计划充当已生成事实。
