# Qwen Image 图像提示词

用于 Qwen Image 的生成与编辑。

## 画面与文字分层描述

描述主体、环境、媒介、光线与布局；含中文文字的道具、海报或信息图，单独列明准确文案、字体风格、层级、留白与阅读顺序，不把文案埋在长段氛围描写中。严格保留用户给出的原文，文字过密时调整排版而非擅自删字。

告示道具图示例：

```text
正面拍摄一张贴在深褐木板上的旧纸告示，纸张完整，边角轻微卷起，文字区平整清楚。米白纸面、黑色墨字，左上方柔光，画面完整容纳四边。
上方居中写大号端正黑体标题“渡口停航”；标题下方居中分两行写略小字号正文“今日大雾”和“明晨再开”，间距均匀；最下方右对齐署名“渡口事务所”，四周留白充足。文字仅包含以上四处。
```

## 编辑时说明变化类型

局部增删、改色或改字，明确目标、变化内容与周围保持项；换姿势、转视角或风格迁移影响范围较大时，分别列出要保住的身份特征与结构关系。

改字示例（假设原图已传入，正式引用使用真实 `<ref input_id="…" label="…" />`）：

```text
仅将告示正文第二行“明晨再开”替换为“午后再开”，保持这一行原有字体、字号、墨色、对齐位置与行距，字形完整清晰。
其余标题、第一行与署名保留原文，纸张卷角、木板纹理、构图、透视与左上方光线不变。
```

多图编辑写明各自提取的对象与目标位置；不自行手写「图1／图2」编号替代真实 `<ref>` 标签，生成能力也不等于编辑能力，操作前确认当前模型支持图像编辑。

## 通道选项与文字核验

应用内 Qwen Image 仅支持通过可选的提示词智能改写选项（`prompt_extend`，以当前型号支持为准）扩写简短创意；**不支持负向提示词参数**，不往正文里硬写不存在的参数。已有精确排版或逐字文案时应留意改写是否改动了细节要求。

看图验收时除了基础质量，重点逐字核对错字、漏字、多字、顺序与排版留白；文字局部出错优先针对失败区域返修，保住其余正确画面。
