# 风格化动作短片：破盾开路

> 原创演示剧情：轻剑者**沈青**要穿过石桥尽头拱门，重盾**机关卫**挡道。她正面击盾受阻，虚晃诱使机关卫重推前冲，借右侧低矮石台绕至盾后击碎**琥珀供能晶体**，使封门三层光障依次碎散开路。胜利标志为“通路开启”，机关卫仍在场。

## 设计与素材分工

- **能力与节奏差异**：机关卫靠沉重踏步与左盾推进，转身迟缓（且盾背外露琥珀晶体连着门内三层光障）；沈青剑尖仅随实斩带出短促青白细弧，不能远程破盾。先演正面失利建立硬度，再以侧步诱导实现反制，最后以近点破晶带动远景逐层散障。
- **可控时长与拆分**：正文按 **15 秒**单次生成编排；若受限于短时长或单镜精度要求，可在“正面受阻定格 → 绕行与击晶”间拆成两段。以下不提前写片头总剧透；实际绑定参考时替换外观重复描写与系统风格。

| 所需素材 | 承担职责 | 起点核验 |
|---|---|---|
| 沈青参考＋银色直剑道具图 | 深靛短衣与金属实体直剑 | 剑身保持金属实体质感，不被青白光弧画成纯光束 |
| 机关卫结构参考 | 铜甲、左臂重盾、盾背外露晶体及能量纹路 | 背面结构清楚，左盾方位不变且晶体高度可够及 |
| 石桥拱门空间与特效参考 | 桥面、右侧连续石台、门内三层错落光障、光效形制 | 石台路线可达盾后，三层光障保持前后间距，光效不遮人 |

## 完整提示词（15 秒四镜头草案）

```text
本段共用锚点：雨后冷灰天光石桥尽头是高大拱门，盾背琥珀晶体发出暖光沿连接纹路通向门内三层前后错落的弧形光障，铜甲与湿石质感清晰，全段无对白与配乐，保留脚步、水声、金属与能量裂鸣。

Shot 1（双人全景·侧面平视·固定·3s）
【0-3s】
首帧：湿润石桥面左侧为持银色直剑的沈青，右侧为左臂架重盾面朝她的机关卫；高大拱门在机关卫身后，盾背微露琥珀晶体及连向门内光障的亮纹，桥右侧低矮石台在远侧连往盾后。双方脚部、剑、盾与石台均可见。
[0-1.5s] 沈青前脚踏入浅水转髋斜劈盾面，剑锋触盾刹那迸出窄小青白火花；机关卫后脚压稳石缝，盾面仅微沉。
[1.5-3s] 机关卫前踏顶盾前推，迫使沈青向后滑退两步、靴底犁出水痕，门内三层光障纹丝不动，伴随沉闷撞击与踏水声。
结束状态：沈青退回左侧仍持银剑，机关卫前移一步拉开与拱门距离，右侧石台通道露出。

Shot 2（双人全景·同侧斜视·横向跟拍·4s）
【3-7s】
首帧：沿用左外侧机位与站位，机关卫面向沈青，门在右后景。
[3-5s] 沈青向盾前虚踏半步随即撤回重心；机关卫踏地扑压原位，沈青趁机侧步滑向右侧低矮石台外侧避开盾缘。
[5-7s] 沈青后脚蹬湿石跃上石台借力绕过重盾侧翼，落至机关卫与拱门之间；摄影机向拱门横移维持全身与落脚点入画。机关卫急停试图抬脚转身，盾背琥珀晶体正好朝向沈青。
结束状态：沈青停在机关卫背后与拱门前，正在转身的机关卫背盾与外露晶体完全对准她。

Shot 3（中景转全景·同侧斜视·先定后拉远·5s）
【7-12s】
首帧：从桥侧斜视盾背，沈青在右抬剑蓄势，机关卫背盾与晶体、连接门内三层光障的纹路在左清晰可见。
[7-8.5s] 沈青转髋挥剑横斩琥珀晶体，接触瞬间闪出细窄青白亮线随后晶体碎裂，琥珀碎屑飞溅、盾臂无力下沉，清脆裂声响起。
[8.5-12s] 暖色光流自纹路熄退；摄影机平稳后退拉出沈青、机关卫与完整拱门的全景，门内近、中、远三层光障依次浮现裂纹并向下散落细碎光点，湿地短暂映出暖光，露出了门后畅通桥路。
结束状态：晶体碎裂、盾臂垂落，三层光障消散，沈青立于机关卫与畅通拱门之间，湿石留有碎片。

Shot 4（环境全景·沿用前镜构图·固定·3s）
【12-15s】
首帧：承接全景，碎片留在湿石上，门前通路敞开。
[12-15s] 沈青收剑垂落身侧走向拱门并迈过门洞；身后机关卫维持垂盾停在原地，光屑渐暗、水面涟漪延续，只留脚步与桥下水声。
结束状态：沈青行过拱门走向前方桥路，身后的机关卫留在原位。
```

> 修正提示：如发现“穿盾而过”“命中前晶体就先碎”或“三层光障同帧消失”，优先核对石台走位参照、首帧是否提前破坏与纵深景别，再微调对应镜头窗口，不以满屏白光掩盖动作；核心验收动作因果（受挫 → 诱冲绕侧 → 实触破晶 → 逐层熄灭开路）。
