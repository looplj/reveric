# 动作对抗：逼退后反制

> 演示剧情：长枪守卫把**剑客**逼退到石柱边，剑客稳住重心后借助地形侧身脱困并夺回近身距。

## 设计取舍

- **先写受力因果，再切近距反制**：不概括写成“两人激烈拼杀三回合”，而是看清双脚支撑、兵器格挡接触面、逼退到达支撑物的真实距离，以及“靠借力/破绽反制”的触发节点。
- 本案例侧重写实冷兵器近身搏斗（与带能量视觉特效的风格化示范 [破盾开路](shot-stylized-action.md) 区分职责）。

## 完整提示词（10 秒两镜头草案）

```text
本段共用锚点：石阶广场阴天散射光，湿石板路面保留轻微水渍，无对白与配乐，突出兵器磕碰与踏步磨地声。

Shot 1（双人全景·侧面平视·固定·5s）
【0-5s】
首帧：石阶广场侧面全景，剑客位于左侧靠近一根粗石柱（距石柱约两步远），右侧枪手双手挺长枪对准剑客胸口；双方双脚与后方石柱完整入画。
[0-2s] 枪手前跨半步直刺，剑客向左斜侧微移并用长剑中段斜架枪杆，将枪尖拨离中线，擦出短促金属摩擦声。
[2-5s] 枪手压肩顶着剑身前推，剑客后脚蹬湿石板接连退步，直到肩背顶靠上粗石柱停住，双手仍横剑隔住枪杆，喘息加重。
结束状态：剑客背靠石柱受压撑剑，枪手前压呈压制态势，双方距离贴近中段兵器长度。

Shot 2（双人中近景·斜侧机位·小幅横移跟进·5s）
【5-10s】
首帧：切到斜侧中近景纳入剑客半身与枪手中段，保持剑客在左背抵石柱、枪手在右发力前压的轴线。
[5-7s] 剑客借石柱支撑向左肩沉重心并顺势旋腕卸力，枪尖擦过石柱边缘掠空刺在空处，在柱面留下一道刮痕。
[7-10s] 枪手前冲力道失衡略微前倾的瞬间，剑客右侧一步滑出柱旁贴近长枪中段内侧，长剑反指枪手腕前迫其急收枪撤步，镜头小幅向右横移保持两人对峙位置并定格。
结束状态：剑客脱困抢至长枪攻击内圈、持剑直指前方，枪手被迫横拉长枪护身，两人局面互换。
```

**验收**：确认“格挡拨偏 → 压迫退至石柱 → 卸力令长枪失衡 → 切入内圈”因果链不断裂，枪尖空刺与剑客借石柱反制有明确空间支点，不出现瞬移或穿模。
