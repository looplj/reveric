# 按实际尾部状态续拍

> 场景背景：原计划“陈叔取下工具箱放上桌面，下一段开箱”，但上一代实际采用结果结束在**双手端箱站立桌前、箱底尚未落桌**的状态（尾部声音为均匀通风底声）。

## 设计取舍

- **按实测末态而非原计划起镜**：先补完尚未发生的“落桌”，再“松手 → 掀盖”，否则就会凭空悬空开箱或重演取箱动作。
- 若同时使用原生尾帧图约束终点，尾帧仅呈现“箱已落桌且对开箱盖敞开”，中间过程仍必须保留接触、放稳与掀盖次序。

## 完整提示词（7 秒单镜头草案）

```text
Shot 1（中近景·平视·固定·7s）
【0-7s】
首帧：陈叔站在木桌后，双手托着未封胶带的厚纸工具箱，箱底悬在桌面上方约十厘米；构图容纳上身、双手、纸箱与桌面，沿用前段实际尾帧的暖白顶灯与取景。
[0-2s] 陈叔平稳下放纸箱，直至箱底落稳接触木桌面发出轻闷响，随后双手离开箱底。
[2-3s] 双手移至箱顶对合的两片纸盖边沿。
[3-5.5s] 陈叔沿原折线向左右掀开两片箱盖，露出箱内暗影。
[5.5-7s] 双手松开箱盖自然停在箱体两侧，室内通风声延续、纸板摩擦声停止。
结束状态：纸箱稳放桌面，两片顶盖敞开，陈叔站在桌后尚未伸手入箱。
```

**验收**：确认未重演取箱、箱底稳妥接触桌面后才开启箱盖，且拼接处通风底声连续（必须实际试听视频，不能仅凭首尾静帧判断声音衔接）。
