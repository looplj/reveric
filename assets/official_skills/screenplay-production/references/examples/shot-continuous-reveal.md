# 连续运动与揭示

> 演示剧情：旅人**顾行**登上高处阶梯，喘息歇脚时无意抬头，首次望见雾气笼罩下的宏大水城。

## 设计取舍

- **先藏后露，靠人物眼神与相机位移协同控制揭晓时刻**：登顶时先看人物反应与前景遮挡（垛口／石栏），先不暴露全景水城；在顾行擦汗停手的瞬间，相机跟随起身平升并越过石栏，按近、中、远景层次揭示水城全貌。
- 注意本段为**单个连贯长镜头**，故不写片头剧透总述，直接在 `Shot 1` 中写清起点与逐层揭晓过程。

## 完整提示词（10 秒单镜头草案）

```text
Shot 1（背面跟拍转侧景再越栏全景·平视转仰升平眺·10s）
【0-10s】
首帧：石阶平台末端，青灰石栏与矮垛墙遮住前景外侧视野；旅人顾行背身微侧站在石阶最后两级，身穿风尘仆仆的亚麻行装、背负行囊，顶部微寒阴天光洒在石面。
[0-3s] 顾行右手扶着斑驳石栏重重踩上最高一级石阶站稳，呼出长气，随行囊沉肩晃动；相机保持在他左后方两步距离缓缓前推并停在他侧肩高度。
[3-5.5s] 顾行抬左臂用袖口擦去额头汗水，刚抬头望向石栏前方时动作猛然停住、呼吸一滞；此时机位维持侧肩近景看清他睁大的眼睛，远方仍被石栏遮蔽。
[5.5-10s] 摄影机沿顾行左肩上方缓缓平升并向石栏外侧推越，以顾行左侧背影作近景参照，按近处石栏瓦檐 → 中景蜿蜒河道与吊桥 → 远景雾气中层叠耸立的高架水城依次显露；风声与水声由远及近清晰起来。
结束状态：顾行半侧面剪影留在左前景仰望，水城宏大轮廓横亘在右前方晨雾水波之上。
```

**验收**：确认揭晓顺序严格按“疲惫登高 → 抬眼停顿反应 → 越过石栏分层展开水城”，石栏遮挡确实存在而非首帧即穿帮全景；风声水声随镜头越栏渐强，不依赖瞬时大远景切镜抢先剧透。
