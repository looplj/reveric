# 交接物件与持有关系

> 演示剧情：**唐岳**把封好的牛皮纸档案袋交给**江禾**。江禾接住，低头看封口。

## 设计取舍

- **先共持、后释放**：接手方（江禾）必须先接触并托稳，原持有者（唐岳）才松手，避免出现两个档案袋、凭空换手或物品悬空。
- **动作过载拆分**：不把“递物＋环绕运镜＋当场拆封”塞进同一镜头，固定机位看清手部归属后再切江禾近景看反应（若后续还需拆封，留作下一镜或下段）。

## 完整提示词（8 秒通用草案）

```text
Shot 1（中近景·微俯拍·固定·5s）
【0-5s】
首帧：靠窗木桌旁，唐岳站左、江禾站右，机位容纳双方躯干、双手与桌沿；左侧窗光照亮桌面。唐岳右手捏住封口完好的牛皮纸档案袋左侧短边，袋身悬在桌面上方，江禾双手垂在身前尚未触碰。
[0-1.5s] 唐岳向江禾递出档案袋，袋身角度与右手捏持点保持不变。
[1.5-3s] 江禾伸左手从下方托住档案袋右半部，两人双手短暂共同托握同一档案袋。
[3-4s] 江禾左手托稳后，唐岳松开右手退回身侧，档案袋完全由江禾左手承托。
[4-5s] 江禾将档案袋顺势收至胸前下方；只有纸张轻擦声与室内安静底声。
结束状态：档案袋由江禾左手承托在胸前，唐岳右手空置退回左侧。

Shot 2（近景·平视·固定·3s）
【5-8s】
首帧：切到江禾单人近景（保持轴线与左侧窗光），档案袋仍在她左手中、位于胸前下方画框下缘。
[5-8s] 江禾垂眼看向左手中的完好档案袋并安静停住，室内底声持续。
结束状态：江禾低头注视左手中尚未开封的档案袋。
```

**验收与迁移要点**：重点看清 `1.5–4s` 的共持与释手次序以及第二镜左手持握是否延续；遇到戒指、钥匙等细小物件，须改用近景手部插入镜头并重写捏握部位，不可照搬大件手势。
