# GPT Image 提示词

用于 GPT Image 系列的生成与编辑。

## 新图与版式组织

简单场景直接写连贯自然语言；多分区或信息图可按区域（或“用途 / 场景 / 主体 / 细节 / 约束”）分段，只留有信息量的段落，不强制五栏、JSON 或英文。

- 先讲清主体和空间/接触关系，再补材质受光与准确文字（文字用引号给出原文、载体与位置）；避免用空洞形容词淹没具体指令。
- 摄影参数仅作观感参考，画风沿用项目已确认设定（已注入风格不重复抄写）。

```text
制作旧式黄铜怀表道具证据图：单只怀表打开置于深灰毛毡上，斜上方观察，表盘与盖内侧同框。表盘为轻微磨损的象牙白珐琅，细黑刻度清晰；盖内侧中央仅横向凹刻“N-04”且朝向观察者，盖外缘有一处浅凹痕。左上方柔光照亮黄铜拉丝与刻痕，背景简洁，表冠与连接铰链完整。
```

## 质地控制与局部降噪修复

默认保留已确认提示词与当前项目画风中的质感要求（如胶片颗粒、纸张肌理、手绘笔触、粗粝织物或特定材质光泽），**不要在普通生图/编辑提示词里机械追加降噪套话**，以免洗掉应有纹理。

只有当**实际生成结果出现非预期暗部噪点、色块或过度锐化光晕**时，才针对目标画面执行定向清理或补充约束：

- **局限于问题区域**：先指出待清理的是噪点/锐化伪影，同时显式保持身份、构图、准确文字、主光向及应保留的材质纹理；
- **复查确认**：清理后对比原图确认小字、远景结构和表面纹理没有被一并抹糊。

## 局部编辑写法

明确区分“改变区域”与“严格保持项”，说明移植对象的透视、尺度与光源融入方式。例如针对已绑定的基底图（正式正文放入对应真实 ref 标签）：

```text
编辑已提供的基底图：本次仅将人物右袖肘部以下改为雨水浸湿后的深色调，布料微重略贴手臂，袖口下方带少量水珠。
保持人物面貌、年龄、发型、姿态、左袖、手中怀表位置与刻字、整体曝光、取景与背景不变；湿布仍维持原面料纹路并服从左上方柔光。
```

需要透明输出时须检查实际通道能力并核对输出文件 alpha 通道（棋盘格图样不是透明）。文字排版出错时定位具体错字、字号或位置再重绘，不靠笼统要求“提高画质”返修。
